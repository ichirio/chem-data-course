# 化学データ分析コースへようこそ

このコースは、**化学を専攻する大学生**が、プログラミングを初歩から身につけるための全105回の教材です。化学はあくまで**題材**で、目的は **Python を使って化学データを扱える力**です。

## このコースの考え方

- **コードを書くのはAI、指示と確認は人間**：いまはコードの多くを AI が書いてくれます。このコースが目指すのは、暗記やタイピングではなく、**AIに的確に指示を出し、出てきたコードと結果が正しいかを見抜ける基礎力**です。データ型・単位・欠損値・浮動小数点誤差・乱数シード・データ漏洩・「SMILES は本当にその化合物か」など、AIが間違えやすく人が確認すべき点を毎回扱います。
- **主武器は Python**：化学の世界はいまや Python が中心です（分子を扱う RDKit、実験データ処理、機械学習、ラボの自動化）。AI時代の共通語でもあります。
- **副武器は R**：統計はやっぱり R が得意。統計の回だけ R を使い、両方を行き来できるようにします。
- **1回1テーマ**：週1回・1時間を想定。小さく積み上げます。コツコツ進めれば必ず力になります。
- **毎回セットで用意**：解説 → コピペで動くコード → **AIに任せるときの指示と確認** → 演習問題（AIが書いたコードの誤りを見つける「検証問題」つき）→ 解答。

## 進め方の約束

!!! tip "おすすめの学び方"
    1. まず本文を読み、コードを**自分の手でコピペして実行**する（出力を必ず確認）。
    2. 出力の意味を、AI（Claude や ChatGPT）に「なぜこうなる？」と聞いてみる。
    3. 演習問題を**自分で解いてから**、解答を開く。
    4. できたコードを共有 GitHub リポジトリに置き、仲間や研究室で見せ合う。

!!! note "AIとの付き合い方"
    答えをAIに書かせるだけでは力になりません。**目的・データの形・単位・期待する出力を伝えて書かせ、自分で動かして、正しいか確かめる**——この「指示する力」と「検証する力」こそ、AI時代にいちばん大事な技能です。各回の「AIに任せるときの指示と確認」節と検証問題で練習し、[第103回](lessons/lesson-103.md)で総まとめをします。
