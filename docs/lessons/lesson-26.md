## 1. 再現性のある乱数

NumPy では `np.random.default_rng(seed)` で**乱数の元（ジェネレータ）**を作ります。`seed`（種）を固定すると、**誰が何度実行しても同じ結果**になります。これは研究の再現性に不可欠です。

```python
import numpy as np

rng = np.random.default_rng(0)       # 種を0に固定

print(rng.uniform(0, 1, 3))          # 0〜1の一様乱数を3個
```

出力:

```text
[0.63696169 0.26978671 0.04097352]
```

!!! warning "seed を固定する習慣を"
    種を固定しないと毎回結果が変わり、「昨日のグラフが再現できない」ことになります。研究・教材では**必ず seed を固定**しましょう。

## 2. 測定のばらつきを模擬する

`normal(平均, 標準偏差, 個数)` で、正規分布に従う乱数を作れます。「真の値100に、標準偏差2の誤差が乗る測定」を5回、といった模擬ができます。

```python
import numpy as np

rng = np.random.default_rng(0)
measurements = rng.normal(100, 2, 5)     # 平均100・標準偏差2 を5個
print(measurements.round(3))
print("平均:", measurements.mean().round(3))
```

出力:

```text
[100.251  99.736 101.281 100.21   98.929]
平均: 100.081
```

真の値100の周りに、ばらついた測定値が得られました。第48回のヒストグラムと組み合わせると、誤差の分布を可視化できます。

## 3. モンテカルロ法：乱数で値を推定する

**モンテカルロ法**は、乱数を大量に使って値を見積もる手法です。例として円周率 π を推定します。1辺2の正方形（面積4）に大量の点を打ち、半径1の円（面積π）に入った割合から π を求めます。

```python
import numpy as np

rng = np.random.default_rng(1)
N = 100_000                              # 点の数（多いほど正確）

x = rng.uniform(-1, 1, N)
y = rng.uniform(-1, 1, N)
inside = (x**2 + y**2) <= 1              # 円の中に入ったか（論理配列）

pi_estimate = 4 * inside.mean()          # 入った割合 × 4
print(f"πの推定値: {pi_estimate:.4f}")
```

出力:

```text
πの推定値: 3.1452
```

真の π（3.14159…）に近い値が得られました。点を増やすほど精度が上がります。

!!! success "化学での応用"
    モンテカルロ法は、分子シミュレーション・拡散・反応確率の計算など、化学の広い分野で使われます。「乱数を大量に振って平均をとる」という発想は、覚えておく価値があります。

## 演習問題

**問1.** `np.random.default_rng(42)` を作り、`normal(50, 5, 10)`（平均50・標準偏差5・10個）の測定値を生成して、その平均と標準偏差（`ddof=1`）を表示してください。

**問2.** 同じ乱数生成器で、`uniform(0, 14, 5)`（0〜14の一様乱数＝ランダムなpH値を5つ）を作って表示してください。

**問3.** モンテカルロ法で π を推定するコード（本文）を、`N = 1_000_000`（100万点）に増やして実行し、`N = 100_000` のときと精度を比べてください（seed は 1 のまま）。

---

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    rng = np.random.default_rng(42)
    m = rng.normal(50, 5, 10)
    print("平均:", m.mean().round(3))
    print("標準偏差:", m.std(ddof=1).round(3))
    ```

    出力:
    ```text
    平均: 48.322
    標準偏差: 4.667
    ```
    真の平均50・標準偏差5に近い値（サンプル数が少ないので少しずれる）。

??? success "問2 の解答"
    ```python
    import numpy as np
    rng = np.random.default_rng(42)
    print(rng.uniform(0, 14, 5).round(2))
    ```

    出力:
    ```text
    [10.84  6.14 12.02  9.76  1.32]
    ```
    （※ 問1と同じ generator を使うと乱数が進むので、これは単独で実行した場合の値です。）

??? success "問3 の解答"
    ```python
    import numpy as np
    rng = np.random.default_rng(1)
    N = 1_000_000
    x = rng.uniform(-1, 1, N)
    y = rng.uniform(-1, 1, N)
    inside = (x**2 + y**2) <= 1
    print(f"πの推定値: {4 * inside.mean():.4f}")
    ```

    出力:
    ```text
    πの推定値: 3.1403
    ```
    100万点にすると、10万点（3.1452）より真の π（3.14159…）に近づきます。点が多いほど精度が上がります。
