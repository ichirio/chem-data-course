## 1. 内積（dot）：掛けて足す

2つのベクトルの**内積**は「位置ごとに掛けて、全部足す」計算です。`np.dot` または `@` で求めます。

```python
import numpy as np

v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

print(np.dot(v1, v2))     # 1*4 + 2*5 + 3*6
print(v1 @ v2)            # @ でも同じ
```

出力:

```text
32
32
```

!!! example "化学での内積：分子量"
    「各元素の個数」と「各元素の原子量」の内積が、そのまま分子量になります。
    ```python
    counts = np.array([2, 1])        # H:2, O:1
    masses = np.array([1.008, 15.999])  # Hの原子量, Oの原子量
    print(counts @ masses)           # 2*1.008 + 1*15.999 = 18.015
    ```
    出力:
    ```text
    18.015
    ```
    第3回では for ループで足していた分子量計算が、内積1つで書けます。

## 2. 行列（2次元配列）

配列を入れ子にすると2次元（行列）になります。

```python
import numpy as np

M = np.array([[1, 2],
              [3, 4]])
print(M)
print("形:", M.shape)     # (行数, 列数)
```

出力:

```text
[[1 2]
 [3 4]]
形: (2, 2)
```

## 3. axis：行方向・列方向に集計

行列の合計は、`axis` で「どの方向にまとめるか」を指定できます。ここは pandas の集計にもつながる重要な考え方です。

```python
import numpy as np

M = np.array([[1, 2],
              [3, 4]])

print(M.sum())            # 全体の合計
print(M.sum(axis=0))      # 列ごと（縦方向にまとめる）
print(M.sum(axis=1))      # 行ごと（横方向にまとめる）
```

出力:

```text
10
[4 6]
[3 7]
```

!!! note "axis の向きの覚え方"
    - `axis=0` … **縦**に潰す＝**列ごと**の集計（列が残る）。`[1+3, 2+4] = [4, 6]`
    - `axis=1` … **横**に潰す＝**行ごと**の集計（行が残る）。`[1+2, 3+4] = [3, 7]`

    最初は迷いますが、「axis=0 は行を消す（列が残る）」と覚えると混乱しません。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「エタノール・グルコース・二酸化炭素の組成を、行＝分子、列＝元素（**C, H, O の順**）の整数の行列にしてください。
    原子量の配列も **同じ C, H, O の順** で作り、行列 `@` ベクトルで3つの分子量を一度に求めてください。
    あわせて、分子ごとの原子の総数を `sum` で求めてください（`axis` を明記）。行列と配列の `shape` も print してください。」

!!! warning "AIの出力で確かめること"
    - 組成行列の**列の順番**と、原子量ベクトルの**並び順**が一致しているか（C, H, O と H, C, O が混ざると、エラーは出ずに誤った分子量になります）。
    - 答えを1つ既知の値と照合する（水 18.015、CO₂ 44.009、グルコース 180.156 g/mol）。
    - `shape` を確認：`(分子数, 元素数) @ (元素数,)` → `(分子数,)` になっているか。
    - 「分子ごと」の集計は `axis=1`（行ごと）、「元素ごと」は `axis=0`（列ごと）。結果の長さが分子数か元素数かで見分けられます。

## 演習問題

**問1.** ベクトル `a = np.array([2, 3, 4])` と `b = np.array([10, 100, 1000])` の内積を、`@` を使って計算してください。

**問2.** メタノール $CH_4O$ の分子量を内積で計算してください。`counts = np.array([1, 4, 1])`（C, H, O）、`masses = np.array([12.011, 1.008, 15.999])`。

**問3.** 行列 `M = np.array([[10, 20, 30], [40, 50, 60]])` について、(a) 全体の合計、(b) 列ごとの合計（axis=0）、(c) 行ごとの合計（axis=1）を表示してください。

**問4.**（検証）次は AI が書いたコードです。3つの分子の分子量と、分子ごとの原子の総数を求めたかったのですが、結果がおかしいようです。問題点を指摘し、直してください。

```python
import numpy as np

# 列の順: C, H, O
counts = np.array([[2, 6, 1],     # エタノール C2H6O
                   [6, 12, 6],    # グルコース C6H12O6
                   [1, 0, 2]])    # 二酸化炭素 CO2
masses = np.array([1.008, 12.011, 15.999])    # H, C, O の原子量

print(counts @ masses)          # 分子量
print(counts.sum(axis=0))       # 分子ごとの原子の総数
```

出力:
```text
[ 90.081 246.174  33.006]
[ 9 18  9]
```

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    a = np.array([2, 3, 4])
    b = np.array([10, 100, 1000])
    print(a @ b)
    ```

    出力:
    ```text
    4320
    ```
    （2×10 + 3×100 + 4×1000 = 20 + 300 + 4000 = 4320）

??? success "問2 の解答"
    ```python
    import numpy as np
    counts = np.array([1, 4, 1])
    masses = np.array([12.011, 1.008, 15.999])
    print(counts @ masses)
    ```

    出力:
    ```text
    32.042
    ```

??? success "問3 の解答"
    ```python
    import numpy as np
    M = np.array([[10, 20, 30], [40, 50, 60]])
    print(M.sum())
    print(M.sum(axis=0))
    print(M.sum(axis=1))
    ```

    出力:
    ```text
    210
    [50 70 90]
    [ 60 150]
    ```

??? success "問4 の解答"
    誤りは2か所です。

    1. **原子量の並び順**：組成は C, H, O の順なのに、原子量は H, C, O の順です。エラーは出ませんが、CO₂ が 33.006 g/mol（正しくは 44.009）になっていることから気づけます。
    2. **axis の向き**：「分子ごと（行ごと）」の合計は `axis=1` です。`axis=0` は元素ごと（列ごと）の合計で、C の総数 9・H の総数 18・O の総数 9 を出しています。

    **修正**：

    ```python
    import numpy as np

    # 列の順: C, H, O
    counts = np.array([[2, 6, 1],     # エタノール C2H6O
                       [6, 12, 6],    # グルコース C6H12O6
                       [1, 0, 2]])    # 二酸化炭素 CO2
    masses = np.array([12.011, 1.008, 15.999])    # C, H, O の原子量（列と同じ順）

    print(counts @ masses)          # 分子量
    print(counts.sum(axis=1))       # 分子ごとの原子の総数
    ```

    出力:
    ```text
    [ 46.069 180.156  44.009]
    [ 9 24  3]
    ```
