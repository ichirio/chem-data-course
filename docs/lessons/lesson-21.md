## 1. 配列（ndarray）を作る

`np.array()` にリストを渡すと、NumPy の配列になります。

```python
import numpy as np

masses = np.array([18.015, 46.069, 180.156])   # 分子量の配列
print(masses)
print(type(masses))
```

出力:

```text
[ 18.015  46.069 180.156]
<class 'numpy.ndarray'>
```

`ndarray`（N次元配列）が NumPy の中心的なデータ型です。

---

## 2. 全要素をまとめて計算（ベクトル化）

配列の強みは、**ループを書かずに全要素へ一括計算**できることです。

```python
import numpy as np

masses = np.array([18.015, 46.069, 180.156])

print(masses * 2)          # 全要素を2倍
print(masses + 10)         # 全要素に10を足す
```

出力:

```text
[ 36.03   92.138 360.312]
[ 28.015  56.069 190.156]
```

リストで同じことをするには for ループが必要でした（第5回）。NumPy なら `masses * 2` だけ。**短く・速い**のが魅力です。

!!! note "リストとの違い"
    ```python
    [1, 2, 3] * 2        # → [1, 2, 3, 1, 2, 3]（リストは繰り返し）
    np.array([1,2,3]) * 2  # → [2 4 6]（配列は各要素を2倍）
    ```
    同じ `* 2` でも意味が違います。数値計算では配列の挙動が便利です。

## 3. 配列どうしの計算

同じ長さの配列どうしは、**位置ごと**に計算されます。

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

print(a + b)      # 位置ごとに足す
print(a * b)      # 位置ごとに掛ける
```

出力:

```text
[11 22 33]
[10 40 90]
```

化学の例：温度の配列をまとめてケルビンに変換。

```python
import numpy as np

temps_C = np.array([0, 25, 50, 100])
temps_K = temps_C + 273.15        # 全要素に一括で足す
print(temps_K)
```

出力:

```text
[273.15 298.15 323.15 373.15]
```

!!! success "なぜ速い？"
    NumPy は内部が C 言語で最適化されており、大量の数値計算が Python のループより**桁違いに速い**です。数千・数万点のデータでは、この差が決定的になります。だから科学計算・データ分析は NumPy が土台なのです。

## 演習問題

**問1.** 分子量の配列 `masses = np.array([18.015, 44.009, 180.156])` を作り、全要素を3倍した配列を表示してください。

**問2.** 温度の配列 `temps_C = np.array([-40, 0, 37, 100])` を、`+ 273.15` で一括してケルビンに変換してください。

**問3.** 2つの配列 `moles = np.array([0.5, 1.0, 2.0])` と `molar_mass = np.array([18.0, 46.0, 180.0])` から、**質量 = 物質量 × モル質量** を位置ごとに計算してください。

---

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    masses = np.array([18.015, 44.009, 180.156])
    print(masses * 3)
    ```

    出力:
    ```text
    [ 54.045 132.027 540.468]
    ```

??? success "問2 の解答"
    ```python
    import numpy as np
    temps_C = np.array([-40, 0, 37, 100])
    print(temps_C + 273.15)
    ```

    出力:
    ```text
    [233.15 273.15 310.15 373.15]
    ```

??? success "問3 の解答"
    ```python
    import numpy as np
    moles = np.array([0.5, 1.0, 2.0])
    molar_mass = np.array([18.0, 46.0, 180.0])
    mass = moles * molar_mass
    print(mass)
    ```

    出力:
    ```text
    [  9.  46. 360.]
    ```
