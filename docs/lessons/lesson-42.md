# 第42回　外れ値の検出

!!! abstract "この回のゴール"
    - 「外れ値」とは何か、なぜ問題かを知る
    - **IQR法**（四分位範囲）で外れ値を機械的に見つける
    - 外れ値を除いた集計と、除く前の集計を比べる
    - 所要時間の目安: 60分
    - 使うデータ：**繰り返し滴定**（NaOH 標準液の滴下量 [mL]、架空データ。1点だけ異常値が混入）

測定ミス・記録ミス・装置の不調などで、ときどき「明らかにおかしい値」が紛れ込みます。これを**外れ値**といい、平均などを大きく狂わせます。

```python
import pandas as pd

data = pd.DataFrame({
    "sample": [f"S{i}" for i in range(1, 11)],
    "value":  [12.1, 12.3, 12.0, 12.4, 12.2, 12.5, 12.1, 25.0, 12.3, 11.9],   # 滴下量 [mL]
})
print("外れ値を含む平均:", round(data["value"].mean(), 3))
```

出力:

```text
外れ値を含む平均: 13.48
```

ほとんどが 12 mL 前後なのに、平均が 13.48 mL。S8 の `25.0`（ビュレットの読み違いや記録ミスが疑われる値）という1点が平均を引き上げています。

---

## 1. IQR法：四分位範囲で外れ値を決める

代表的な方法が **IQR法**です。データの真ん中50%が入る幅（IQR）を基準に、そこから大きく外れた点を外れ値とみなします。

$$ \text{IQR} = Q_3 - Q_1, \quad \text{下限}=Q_1 - 1.5\,\text{IQR}, \quad \text{上限}=Q_3 + 1.5\,\text{IQR} $$

- $Q_1$（第1四分位数）… 下から25%の位置の値
- $Q_3$（第3四分位数）… 下から75%の位置の値

```python
q1 = data["value"].quantile(0.25)
q3 = data["value"].quantile(0.75)
iqr = q3 - q1
low = q1 - 1.5 * iqr
high = q3 + 1.5 * iqr

print(f"Q1={q1}, Q3={q3}, IQR={iqr:.3f}")
print(f"正常範囲: {low:.3f} 〜 {high:.3f}")
```

出力:

```text
Q1=12.1, Q3=12.375, IQR=0.275
正常範囲: 11.688 〜 12.788
```

「11.688〜12.788 の外は外れ値」と決まりました。25.0 は明らかに範囲外です。

---

## 2. 外れ値に印をつける

範囲外かどうかを判定する列を作ります（第34回の条件抽出の応用）。

```python
data["is_outlier"] = (data["value"] < low) | (data["value"] > high)
print(data)
```

出力:

```text
  sample  value  is_outlier
0     S1   12.1       False
1     S2   12.3       False
2     S3   12.0       False
3     S4   12.4       False
4     S5   12.2       False
5     S6   12.5       False
6     S7   12.1       False
7     S8   25.0        True
8     S9   12.3       False
9    S10   11.9       False
```

S8 だけが `True`（外れ値）と正しく検出できました。

---

## 3. 外れ値を除いて集計し直す

外れ値でない行だけで平均を取り直します。

```python
clean = data[~data["is_outlier"]]      # ~ は「否定」（外れ値でない行）
print("外れ値を除いた平均:", round(clean["value"].mean(), 3))
print("除いた件数:", data["is_outlier"].sum())
```

出力:

```text
外れ値を除いた平均: 12.2
除いた件数: 1
```

平均が 13.48 → **12.2** と、実態に近い値になりました。

!!! warning "外れ値は「勝手に消してよい」わけではない"
    外れ値が**測定ミス**なら除いてよいですが、**本物の重要な発見**（想定外の反応など）かもしれません。機械的に消す前に「なぜこの値が出たか」を必ず考え、**除いた事実と理由を記録**しましょう（研究の誠実さ）。IQR法はあくまで「候補を見つける」道具です。データが10点程度と少ないと Q1・Q3 自体が不安定なので、判定結果は元の値と並べて必ず目で確認しましょう。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    pandas の DataFrame `data`（列: sample, value = 同じ試料の繰り返し滴定の滴下量 [mL]、10点）について、IQR 法で外れ値候補を判定してください。
    Q1・Q3・IQR・下限・上限を print し、**下限より小さい値と上限より大きい値の両方**を is_outlier=True にしてください。
    外れ値候補の行を表示し、それを除いた平均と件数、除く前の平均を並べて表示してください。行は削除せず、印を付けるだけにしてください。

!!! warning "AIの出力で確かめること"
    - 判定が**両側**になっているか。`value > high` だけだと、小数点の打ち間違い（12.2 → 1.22）のような**小さすぎる**外れ値を見逃します。
    - 除外の向き。`data[~data["is_outlier"]]` の `~` が抜けると、逆に外れ値だけが残ります。除外後の件数（`len(clean)`）と平均が妥当か（12 mL 前後か）を確認します。
    - 平均±2σ で判定するコードになっていないか。外れ値自身が平均と標準偏差を大きくするので、n が小さいと外れ値が範囲に紛れ込むことがあります。この回では IQR 法を使います。
    - 外れ値を**黙って削除**していないか。印を付けた表を残し、除いた行と理由を記録するコードになっているかを見ます。

## 演習問題

**問1.** 本文の `data` で、`value` 列の $Q_1$・$Q_3$・IQR を計算して表示してください。

**問2.** IQR法の下限・上限を計算し、`is_outlier` 列を作って、外れ値の行だけを取り出して表示してください。

**問3.** 外れ値を除いたデータで、平均と**標準偏差**（`.std()`）を小数第3位まで表示してください。外れ値を含む場合と比べて、標準偏差はどう変わりますか？

**問4.**（検証型）別の日の滴定データ（S5 は記録時に小数点を打ち間違えた疑いあり）で、AI が次のコードを書きました。「外れ値を除いた平均」が 25.0 になっています。問題点を**2つ**指摘し、直してください。

```python
data = pd.DataFrame({
    "sample": [f"S{i}" for i in range(1, 11)],
    "value":  [12.1, 12.3, 12.0, 12.4, 1.22, 12.5, 12.1, 25.0, 12.3, 11.9],
})
q1 = data["value"].quantile(0.25)
q3 = data["value"].quantile(0.75)
iqr = q3 - q1
low = q1 - 1.5 * iqr
high = q3 + 1.5 * iqr

data["is_outlier"] = data["value"] > high
clean = data[data["is_outlier"]]
print("外れ値を除いた平均:", round(clean["value"].mean(), 3))
```

出力:
```text
外れ値を除いた平均: 25.0
```

---

## 解答

??? success "問1 の解答"
    ```python
    q1 = data["value"].quantile(0.25)
    q3 = data["value"].quantile(0.75)
    print(f"Q1={q1}, Q3={q3}, IQR={q3 - q1:.3f}")
    ```

    出力:
    ```text
    Q1=12.1, Q3=12.375, IQR=0.275
    ```

??? success "問2 の解答"
    ```python
    low = q1 - 1.5 * (q3 - q1)
    high = q3 + 1.5 * (q3 - q1)
    data["is_outlier"] = (data["value"] < low) | (data["value"] > high)
    print(data[data["is_outlier"]])
    ```

    出力:
    ```text
      sample  value  is_outlier
    7     S8   25.0        True
    ```

??? success "問3 の解答"
    ```python
    clean = data[~data["is_outlier"]]
    print("平均:", round(clean["value"].mean(), 3))
    print("標準偏差(除外後):", round(clean["value"].std(), 3))
    print("標準偏差(除外前):", round(data["value"].std(), 3))
    ```

    出力:
    ```text
    平均: 12.2
    標準偏差(除外後): 0.194
    標準偏差(除外前): 4.052
    ```

    外れ値を除くと標準偏差が **4.052 → 0.194** と激減します。1点の外れ値がばらつきをどれほど歪めるかが分かります。

??? success "問4 の解答"
    **誤り1（判定が片側だけ）**：`data["value"] > high` だけなので、下限より小さい S5 の 1.22 mL を見逃しています。`(data["value"] < low) | (data["value"] > high)` と両側を判定します。

    **誤り2（抽出の向き）**：`data[data["is_outlier"]]` は「外れ値**だけ**」を取り出します。外れ値を除くには否定の `~` を付けます。平均が 25.0 という、ほとんどの測定値（約 12 mL）とかけ離れた値になった時点で気づけます。

    ```python
    print(f"正常範囲: {low:.3f} 〜 {high:.3f}")

    data["is_outlier"] = (data["value"] < low) | (data["value"] > high)
    print(data[data["is_outlier"]])
    clean = data[~data["is_outlier"]]
    print(f"外れ値を除いた平均: {clean['value'].mean():.3f}（{len(clean)} 件）")
    ```

    出力:
    ```text
    正常範囲: 11.500 〜 12.900
      sample  value  is_outlier
    4     S5   1.22        True
    7     S8  25.00        True
    外れ値を除いた平均: 12.200（8 件）
    ```

    （修正版は、問題文の `data` 〜 `high` までを実行した後に続けて実行します。S5・S8 は除く前に、記録ミスかどうかを実験ノートで確認しましょう。）

## この回のまとめ

- 外れ値は平均・標準偏差を大きく狂わせる。
- IQR法：`Q1 - 1.5·IQR` 〜 `Q3 + 1.5·IQR` の外を外れ値とみなす。
- `quantile(0.25)` / `quantile(0.75)` で四分位数、条件抽出で印付け。
- `~条件` は「その否定」。外れ値でない行の抽出に使う。
- **機械的に消さない**。理由を考え、除いた事実を記録する。
