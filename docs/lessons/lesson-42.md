# 第42回　外れ値の検出

!!! abstract "この回のゴール"
    - 「外れ値」とは何か、なぜ問題かを知る
    - **IQR法**（四分位範囲）で外れ値を機械的に見つける
    - 外れ値を除いた集計と、除く前の集計を比べる
    - 所要時間の目安: 60分
    - 使うデータ：**繰り返し測定**（1点だけ異常値が混入）

測定ミス・記録ミス・装置の不調などで、ときどき「明らかにおかしい値」が紛れ込みます。これを**外れ値**といい、平均などを大きく狂わせます。

```python
import pandas as pd

data = pd.DataFrame({
    "sample": [f"S{i}" for i in range(1, 11)],
    "value":  [12.1, 12.3, 12.0, 12.4, 12.2, 12.5, 12.1, 25.0, 12.3, 11.9],
})
print("外れ値を含む平均:", round(data["value"].mean(), 3))
```

出力:

```text
外れ値を含む平均: 13.48
```

ほとんどが12前後なのに、平均が13.48。S8 の `25.0` という1点が平均を引き上げています。

---

## 1. IQR法：四分位範囲で外れ値を決める

代表的な方法が **IQR法**です。データの真ん中50%が入る幅（IQR）を基準に、そこから大きく外れた点を外れ値とみなします。

$$ \text{IQR} = Q_3 - Q_1, \quad \text{下限}=Q_1 - 1.5\,\text{IQR}, \quad \text{上限}=Q_3 + 1.5\,\text{IQR} $$

- $Q_1$（第1四分位数）… 下から25%の位置の値
- $Q_3$（第3四分位数）… 下から75%の位置の値

```python
q1 = data["value"].quantile(0.25)
q3 = data["value"].quantile(0.75)
iqr = q3 - q1
low = q1 - 1.5 * iqr
high = q3 + 1.5 * iqr

print(f"Q1={q1}, Q3={q3}, IQR={iqr:.3f}")
print(f"正常範囲: {low:.3f} 〜 {high:.3f}")
```

出力:

```text
Q1=12.1, Q3=12.375, IQR=0.275
正常範囲: 11.688 〜 12.788
```

「11.688〜12.788 の外は外れ値」と決まりました。25.0 は明らかに範囲外です。

---

## 2. 外れ値に印をつける

範囲外かどうかを判定する列を作ります（第34回の条件抽出の応用）。

```python
data["is_outlier"] = (data["value"] < low) | (data["value"] > high)
print(data)
```

出力:

```text
  sample  value  is_outlier
0     S1   12.1       False
1     S2   12.3       False
2     S3   12.0       False
3     S4   12.4       False
4     S5   12.2       False
5     S6   12.5       False
6     S7   12.1       False
7     S8   25.0        True
8     S9   12.3       False
9    S10   11.9       False
```

S8 だけが `True`（外れ値）と正しく検出できました。

---

## 3. 外れ値を除いて集計し直す

外れ値でない行だけで平均を取り直します。

```python
clean = data[~data["is_outlier"]]      # ~ は「否定」（外れ値でない行）
print("外れ値を除いた平均:", round(clean["value"].mean(), 3))
print("除いた件数:", data["is_outlier"].sum())
```

出力:

```text
外れ値を除いた平均: 12.2
除いた件数: 1
```

平均が 13.48 → **12.2** と、実態に近い値になりました。

!!! warning "外れ値は「勝手に消してよい」わけではない"
    外れ値が**測定ミス**なら除いてよいですが、**本物の重要な発見**（想定外の反応など）かもしれません。機械的に消す前に「なぜこの値が出たか」を必ず考え、**除いた事実と理由を記録**しましょう（研究の誠実さ）。IQR法はあくまで「候補を見つける」道具です。

---

## 演習問題

**問1.** 本文の `data` で、`value` 列の $Q_1$・$Q_3$・IQR を計算して表示してください。

**問2.** IQR法の下限・上限を計算し、`is_outlier` 列を作って、外れ値の行だけを取り出して表示してください。

**問3.** 外れ値を除いたデータで、平均と**標準偏差**（`.std()`）を小数第3位まで表示してください。外れ値を含む場合と比べて、標準偏差はどう変わりますか？

---

## 解答

??? success "問1 の解答"
    ```python
    q1 = data["value"].quantile(0.25)
    q3 = data["value"].quantile(0.75)
    print(f"Q1={q1}, Q3={q3}, IQR={q3 - q1:.3f}")
    ```

    出力:
    ```text
    Q1=12.1, Q3=12.375, IQR=0.275
    ```

??? success "問2 の解答"
    ```python
    low = q1 - 1.5 * (q3 - q1)
    high = q3 + 1.5 * (q3 - q1)
    data["is_outlier"] = (data["value"] < low) | (data["value"] > high)
    print(data[data["is_outlier"]])
    ```

    出力:
    ```text
      sample  value  is_outlier
    7     S8   25.0        True
    ```

??? success "問3 の解答"
    ```python
    clean = data[~data["is_outlier"]]
    print("平均:", round(clean["value"].mean(), 3))
    print("標準偏差(除外後):", round(clean["value"].std(), 3))
    print("標準偏差(除外前):", round(data["value"].std(), 3))
    ```

    出力:
    ```text
    平均: 12.2
    標準偏差(除外後): 0.194
    標準偏差(除外前): 4.052
    ```

    外れ値を除くと標準偏差が **4.052 → 0.194** と激減します。1点の外れ値がばらつきをどれほど歪めるかが分かります。

---

## この回のまとめ

- 外れ値は平均・標準偏差を大きく狂わせる。
- IQR法：`Q1 - 1.5·IQR` 〜 `Q3 + 1.5·IQR` の外を外れ値とみなす。
- `quantile(0.25)` / `quantile(0.75)` で四分位数、条件抽出で印付け。
- `~条件` は「その否定」。外れ値でない行の抽出に使う。
- **機械的に消さない**。理由を考え、除いた事実を記録する。
