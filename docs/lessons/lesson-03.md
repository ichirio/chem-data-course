## 1. リスト：値を順番に並べてしまう箱

前回は変数1つに値を1つ入れました。でも元素は100種類以上あります。1つずつ変数を作るのは大変です。
**リスト**を使うと、たくさんの値を1つの名前でまとめられます。角かっこ `[ ]` で作ります。

```python
# 有機化学でよく出る元素を並べる
elements = ["H", "C", "N", "O"]

print(elements)          # 全体を表示
print(len(elements))     # 要素の個数 → 4
```

出力:

```text
['H', 'C', 'N', 'O']
4
```

### 番号（インデックス）で取り出す

リストの中身は**0番から**数えます（1番からではないので注意！）。

```python
elements = ["H", "C", "N", "O"]

print(elements[0])    # 最初 → H
print(elements[1])    # 2番目 → C
print(elements[-1])   # 最後 → O（マイナスは後ろから数える）
```

### 後から追加する

```python
elements = ["H", "C", "N", "O"]
elements.append("P")     # 末尾にリンを追加
elements.append("S")     # 硫黄も追加
print(elements)          # ['H', 'C', 'N', 'O', 'P', 'S']
```

## 2. for ループ：リストを1つずつ処理する

リストの中身を順番に取り出して、同じ処理を繰り返すのが **for ループ**です。

```python
elements = ["H", "C", "N", "O"]

for e in elements:
    print(f"元素記号: {e}")
```

出力:

```text
元素記号: H
元素記号: C
元素記号: N
元素記号: O
```

!!! warning "インデント（字下げ）が命"
    `for` の行の下は、**必ず半角スペース4つで字下げ**します。この字下げが「ループの中でやること」を表します。VS Code では自動で下げてくれますが、ずれるとエラーになるので意識しましょう。

番号もいっしょに欲しいときは `enumerate` を使います。

```python
elements = ["H", "C", "N", "O"]

for i, e in enumerate(elements, start=1):
    print(f"{i}番目の元素は {e}")
```

出力:

```text
1番目の元素は H
2番目の元素は C
3番目の元素は N
4番目の元素は O
```

## 3. 辞書：名前で値を引く「表」

リストは「順番」で値を取り出しました。でも原子量は「H といえば 1.008」のように、**名前で引きたい**ですよね。
そこで **辞書（dictionary）** を使います。波かっこ `{ }` で「キー: 値」の組を並べます。

```python
# 原子量表（キー = 元素記号、値 = 原子量）
atomic_mass = {
    "H": 1.008,
    "C": 12.011,
    "N": 14.007,
    "O": 15.999,
}

print(atomic_mass["O"])    # O の原子量を引く → 15.999
print(atomic_mass["C"])    # C の原子量を引く → 12.011
```

出力:

```text
15.999
12.011
```

これはまさに、プログラムの中に持ち歩ける「原子量表」です。

### 辞書をループする

```python
atomic_mass = {"H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999}

for symbol, mass in atomic_mass.items():
    print(f"{symbol} の原子量は {mass}")
```

出力:

```text
H の原子量は 1.008
C の原子量は 12.011
N の原子量は 14.007
O の原子量は 15.999
```

## 4. リスト＋辞書で分子量を計算する

いよいよ本番。分子は「どの元素が何個あるか」で決まります。これも辞書で表せます。

**例題**: エタノール $C_2H_6O$ のモル質量を求める。

```python
# 原子量表
atomic_mass = {"H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999}

# エタノール C2H6O の組成（元素: 個数）
ethanol = {"C": 2, "H": 6, "O": 1}

# 各元素の (原子量 × 個数) を足し合わせる
total = 0.0
for symbol, count in ethanol.items():
    contribution = atomic_mass[symbol] * count
    print(f"{symbol}: {atomic_mass[symbol]} × {count} = {contribution:.3f}")
    total = total + contribution

print(f"エタノールのモル質量は {total:.3f} g/mol")
```

出力:

```text
C: 12.011 × 2 = 24.022
H: 1.008 × 6 = 6.048
O: 15.999 × 1 = 15.999
エタノールのモル質量は 46.069 g/mol
```

!!! success "ここが第1部の山場"
    「原子量表（辞書）」と「分子の組成（辞書）」を、for ループで掛け合わせて足す——この考え方は、この先ずっと使います。次回以降、これを**関数**にまとめて、どんな分子でも一発で計算できるようにしていきます。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    元素記号をキー、原子量 [g/mol] を値とする辞書 `atomic_mass`（H, C, N, O, Cl）と、分子の組成を `{元素記号: 個数}` の辞書で表したものから、モル質量を for ループで計算する Python コードを書いてください。
    対象はエタノール C2H6O・酢酸 C2H4O2・クロロホルム CHCl3 です。

!!! warning "AIの出力で確かめること"
    - 組成の辞書に同じキーが2回出ていないか。`{"C": 1, "H": 3, "C": 1}` のように書くとエラーにならず、後の値で**黙って上書き**されます。`print(組成の辞書)` で中身を見ます。

    - 原子量表の値が本文の表と一致しているか（桁の打ち間違い、`35.45` と `35.453` の混在など）。
    - 元素記号の大文字・小文字。`"CL"` や `"cl"` では `KeyError` になります。
    - 既知の値で検算：エタノール 46.069 g/mol、酢酸 60.052 g/mol。

**問1.** ハロゲン元素のリスト `["F", "Cl", "Br", "I"]` を作り、for ループで「◯番目のハロゲンは △」と番号つきで表示してください（`enumerate` を使う）。

**問2.** 原子量表の辞書に、ナトリウム `"Na": 22.990` と塩素 `"Cl": 35.453` を加えてください。そのうえで、**塩化ナトリウム NaCl（Na 1個・Cl 1個）のモル質量**を計算して表示してください。

**問3.** 本文のエタノールの計算をまねて、**酢酸 $C_2H_4O_2$（C 2個・H 4個・O 2個）のモル質量**を計算してください。原子量表は本文のものを使います。


**問4.**（検証）次は、酢酸 CH₃COOH のモル質量を求めるよう AI に頼んで出てきたコードです。エラーは出ずに `酢酸のモル質量は 45.017 g/mol` と表示されました。どこがおかしいのかを指摘し、直してください。

```python
atomic_mass = {"H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999}

# 酢酸 CH3COOH を、構造式の順に書き写した組成
acetic_acid = {"C": 1, "H": 3, "C": 1, "O": 2, "H": 1}

total = 0.0
for symbol, count in acetic_acid.items():
    total = total + atomic_mass[symbol] * count

print(f"酢酸のモル質量は {total:.3f} g/mol")
```

??? success "問4 の解答"
    **問題点：辞書のキーが重複している。** 辞書では同じキーを2回書くと、エラーにならずに**後の値で上書き**されます。`print(acetic_acid)` で確かめると、C と H が1個ずつしか残っていないことが分かります。
    ```python
    acetic_acid = {"C": 1, "H": 3, "C": 1, "O": 2, "H": 1}
    print(acetic_acid)
    ```

    出力:
    ```text
    {'C': 1, 'H': 1, 'O': 2}
    ```

    化学の目でも、酢酸（C2H4O2）は本文の問3で 60.052 g/mol と求めているので、45.017 はおかしいと気づけます。

    **修正版**（同じ元素は個数を合計して1つのキーにまとめる）：
    ```python
    atomic_mass = {"H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999}

    # 酢酸 CH3COOH = C2H4O2（同じ元素は個数を合計して1つのキーにまとめる）
    acetic_acid = {"C": 2, "H": 4, "O": 2}
    print(acetic_acid)     # 組成を目で確認する

    total = 0.0
    for symbol, count in acetic_acid.items():
        total = total + atomic_mass[symbol] * count

    print(f"酢酸のモル質量は {total:.3f} g/mol")
    ```

    出力:
    ```text
    {'C': 2, 'H': 4, 'O': 2}
    酢酸のモル質量は 60.052 g/mol
    ```
