## 1. Python は賢い電卓

まずは計算から。次を `lesson02.py` に書いて実行してみましょう。

```python
print(1 + 2)      # 足し算 → 3
print(10 - 3)     # 引き算 → 7
print(4 * 5)      # 掛け算 → 20
print(7 / 2)      # 割り算 → 3.5（小数で返る）
print(2 ** 10)    # べき乗（2の10乗）→ 1024
print(17 // 5)    # 割り算の「商」だけ → 3
print(17 % 5)     # 割り算の「あまり」→ 2
```

出力:

```text
3
7
20
3.5
1024
3
2
```

!!! note "`print()` って何？"
    `print(...)` は「かっこの中身を画面に表示して」という命令です。プログラムは書いただけでは何も見えません。**結果を見たいときは `print()` で包む**——これが基本です。

## 2. 変数：計算結果に名前をつけてしまっておく

同じ数を何度も使うなら、**変数**に入れておくと便利です。`=` は「右の値を左の名前に入れる」という意味です（数学の「等しい」ではありません）。

```python
# アボガドロ定数と、水素・酸素の原子量を変数に入れる
avogadro = 6.022e23    # 6.022 × 10^23 を e で表す書き方
mass_H = 1.008         # 水素の原子量
mass_O = 15.999        # 酸素の原子量

# 変数を使って水の分子量を計算
mass_water = mass_H * 2 + mass_O
print("水の分子量:", mass_water)
```

出力:

```text
水の分子量: 18.015
```

一度 `mass_water` に入れておけば、この後は `mass_water` と書くだけで 18.015 を呼び出せます。

## 3. データ型：数と文字は種類が違う

Python が扱うデータには「型（かた）」があります。まずは3つ覚えれば十分です。

| 型 | 意味 | 例 |
|---|---|---|
| `int` | 整数 | `3`, `-10`, `100` |
| `float` | 小数 | `1.008`, `3.5`, `6.022e23` |
| `str` | 文字列 | `"水"`, `"H2O"` |

`type()` で型を確認できます。

```python
print(type(3))          # <class 'int'>
print(type(1.008))      # <class 'float'>
print(type("H2O"))      # <class 'str'>
```

!!! warning "文字列はクォートで囲む"
    文字は必ず `"` または `'` で囲みます。`print(H2O)` と書くと「H2Oという名前の変数を探して」という意味になり、エラーになります。`print("H2O")` が正解です。

## 4. f-string：文と数をきれいに並べて表示する

文字列の前に `f` をつけると、`{ }` の中に変数や計算を埋め込めます。これを **f-string** と呼びます。とても便利なので必ず使えるようにしましょう。

```python
name = "水"
formula = "H2O"
mass_water = 18.015

print(f"{name} ({formula}) のモル質量は {mass_water} g/mol です")

# 小数点以下の桁数もそろえられる（:.2f は「小数第2位まで」）
print(f"約 {mass_water:.2f} g/mol")
```

出力:

```text
水 (H2O) のモル質量は 18.015 g/mol です
約 18.02 g/mol
```

!!! note "「分子量」と「モル質量」"
    分子量（相対分子質量）は単位のない数（水なら 18.015）、モル質量は 1 mol あたりの質量で単位は g/mol（水なら 18.015 g/mol）です。数値は同じですが、**g/mol を付けるときは「モル質量」**と呼びます。

## 5. 化学で使う：モル計算をやってみる

ここまでを組み合わせて、化学の基本計算をプログラムにします。

**例題**: 水 36.0 g は何モルで、分子は何個あるか？

$$ \text{物質量 [mol]} = \frac{\text{質量 [g]}}{\text{モル質量 [g/mol]}} $$

```python
# --- 入力する値 ---
mass_water = 18.015     # 水のモル質量 [g/mol]
avogadro = 6.022e23     # アボガドロ定数 [個/mol]
sample_g = 36.0         # 手元にある水の質量 [g]

# --- 計算 ---
moles = sample_g / mass_water          # 物質量 [mol]
molecules = moles * avogadro           # 分子の個数 [個]

# --- 表示 ---
print(f"水 {sample_g} g は {moles:.3f} mol です")
print(f"分子はおよそ {molecules:.3e} 個あります")
```

出力:

```text
水 36.0 g は 1.998 mol です
分子はおよそ 1.203e+24 個あります
```

!!! tip "`:.3e` の意味"
    `e` は指数表記（`1.203e+24` は 1.203 × 10²⁴）。とても大きい／小さい数はこの形が読みやすいです。`.3` は**小数点以下の桁数**で、仮数部が `1.203` のように小数点以下3桁（有効数字でいえば4桁）になります。有効数字3桁で表示したいときは `:.2e`（→ `1.20e+24`）です。

!!! example "AIへの頼み方（例）"
    Python の標準機能だけ（ライブラリなし）で、錠剤に含まれるアスピリン C9H8O4 330 mg の物質量 [mol] と分子数を計算するコードを書いてください。

    結果は f-string で、モル質量は小数第3位まで、物質量と分子数は指数表記・有効数字3桁で表示してください。

!!! warning "AIの出力で確かめること"
    - mg → g の換算（`/ 1000`）の行があるか。変数名・コメントの単位と、実際に入っている値の単位が一致しているか。
    - 式の向き：物質量 = 質量 ÷ モル質量、分子数 = 物質量 **×** アボガドロ定数。分子数が 1 より小さいなど、桁が明らかにおかしくないか。

    - 途中の値を丸めてから次の計算に使っていないか（丸めるのは表示のときだけ）。

## 演習問題

**問1.** ブドウ糖（グルコース）$C_6H_{12}O_6$ のモル質量を計算して表示してください。
原子量は C = 12.011、H = 1.008、O = 15.999 とします。f-string を使って「グルコースのモル質量は ○○ g/mol です」と表示しましょう。

**問2.** 問1で求めたモル質量を使って、**グルコース 90.0 g が何モルか**を計算し、小数第3位まで表示してください。

**問3.** 問2のモル数から、**グルコース分子が何個あるか**を指数表記（`:.3e`）で表示してください。アボガドロ定数は `6.022e23` とします。


**問4.**（検証）次は、「鎮痛薬 1 錠に含まれるアスピリン（C9H8O4）330 mg の分子数」を求めるよう AI に頼んで出てきたコードと、その出力です。問題点を2つ指摘し、直してください。

```python
# 鎮痛薬 1 錠に含まれるアスピリン（C9H8O4）330 mg の分子数を求める
mass_C = 12.011
mass_H = 1.008
mass_O = 15.999
avogadro = 6.022e23

aspirin = mass_C * 9 + mass_H * 8 + mass_O * 4   # モル質量 [g/mol]
tablet_mg = 330                                  # 1 錠中のアスピリン [mg]
moles = tablet_mg / aspirin
molecules = moles / avogadro
print(f"モル質量: {aspirin:.3f} g/mol")
print(f"物質量: {moles:.3e} mol")
print(f"分子数: {molecules:.3e} 個")
```

出力:
```text
モル質量: 180.159 g/mol
物質量: 1.832e+00 mol
分子数: 3.042e-24 個
```

---

## 解答

??? success "問1 の解答"
    ```python
    mass_C = 12.011
    mass_H = 1.008
    mass_O = 15.999

    glucose = mass_C * 6 + mass_H * 12 + mass_O * 6
    print(f"グルコースのモル質量は {glucose:.3f} g/mol です")
    ```

    出力:
    ```text
    グルコースのモル質量は 180.156 g/mol です
    ```

??? success "問2 の解答"
    ```python
    glucose = 180.156        # 問1の結果
    sample_g = 90.0
    moles = sample_g / glucose
    print(f"グルコース {sample_g} g は {moles:.3f} mol です")
    ```

    出力:
    ```text
    グルコース 90.0 g は 0.500 mol です
    ```

    （ほぼ半モルです。正確には 0.49957… mol で、小数第3位に丸めると 0.500 になります。）

??? success "問3 の解答"
    ```python
    glucose = 180.156
    sample_g = 90.0
    avogadro = 6.022e23
    moles = sample_g / glucose        # 丸めた 0.500 ではなく、計算結果そのものを使う
    molecules = moles * avogadro
    print(f"分子はおよそ {molecules:.3e} 個あります")
    ```

    出力:
    ```text
    分子はおよそ 3.008e+23 個あります
    ```

    表示用に丸めた `0.500` を使うと `3.011e+23` になり、少しずれます。**途中の値は丸めずに使い、丸めるのは表示のときだけ**にしましょう。


??? success "問4 の解答"
    **問題点1：mg を g に直していない。** モル質量は g/mol なので、質量も g にしてから割る必要があります。330 mg の錠剤が 1.8 mol（約 330 g 分）になっているのは明らかにおかしい値です。

    **問題点2：分子数をアボガドロ定数で「割って」いる。** 分子数 = 物質量 × アボガドロ定数です。「分子数が 1 個より少ない」という出力は、化学的にありえません。

    **確かめ方**：出力の桁を常識と比べます（1 錠は 1 g 未満 → 物質量は 10⁻³ mol 程度、分子数は 10²¹ 個程度のはず）。

    **修正版**：
    ```python
    # 鎮痛薬 1 錠に含まれるアスピリン（C9H8O4）330 mg の分子数を求める
    mass_C = 12.011
    mass_H = 1.008
    mass_O = 15.999
    avogadro = 6.022e23

    aspirin = mass_C * 9 + mass_H * 8 + mass_O * 4   # モル質量 [g/mol]
    tablet_mg = 330                                  # 1 錠中のアスピリン [mg]
    tablet_g = tablet_mg / 1000                      # mg → g に換算
    moles = tablet_g / aspirin                       # [mol]
    molecules = moles * avogadro                     # [個]
    print(f"モル質量: {aspirin:.3f} g/mol")
    print(f"物質量: {moles:.3e} mol")
    print(f"分子数: {molecules:.3e} 個")
    ```

    出力:
    ```text
    モル質量: 180.159 g/mol
    物質量: 1.832e-03 mol
    分子数: 1.103e+21 個
    ```
