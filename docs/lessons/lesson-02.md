## 1. Python は賢い電卓

まずは計算から。次を `lesson02.py` に書いて実行してみましょう。

```python
print(1 + 2)      # 足し算 → 3
print(10 - 3)     # 引き算 → 7
print(4 * 5)      # 掛け算 → 20
print(7 / 2)      # 割り算 → 3.5（小数で返る）
print(2 ** 10)    # べき乗（2の10乗）→ 1024
print(17 // 5)    # 割り算の「商」だけ → 3
print(17 % 5)     # 割り算の「あまり」→ 2
```

出力:

```text
3
7
20
3.5
1024
3
2
```

!!! note "`print()` って何？"
    `print(...)` は「かっこの中身を画面に表示して」という命令です。プログラムは書いただけでは何も見えません。**結果を見たいときは `print()` で包む**——これが基本です。

## 2. 変数：計算結果に名前をつけてしまっておく

同じ数を何度も使うなら、**変数**に入れておくと便利です。`=` は「右の値を左の名前に入れる」という意味です（数学の「等しい」ではありません）。

```python
# アボガドロ定数と、水の原子量を変数に入れる
avogadro = 6.022e23    # 6.022 × 10^23 を e で表す書き方
mass_H = 1.008         # 水素の原子量
mass_O = 15.999        # 酸素の原子量

# 変数を使って水の分子量を計算
mass_water = mass_H * 2 + mass_O
print("水の分子量:", mass_water)
```

出力:

```text
水の分子量: 18.015
```

一度 `mass_water` に入れておけば、この後は `mass_water` と書くだけで 18.015 を呼び出せます。

## 3. データ型：数と文字は種類が違う

Python が扱うデータには「型（かた）」があります。まずは3つ覚えれば十分です。

| 型 | 意味 | 例 |
|---|---|---|
| `int` | 整数 | `3`, `-10`, `100` |
| `float` | 小数 | `1.008`, `3.5`, `6.022e23` |
| `str` | 文字列 | `"水"`, `"H2O"` |

`type()` で型を確認できます。

```python
print(type(3))          # <class 'int'>
print(type(1.008))      # <class 'float'>
print(type("H2O"))      # <class 'str'>
```

!!! warning "文字列はクォートで囲む"
    文字は必ず `"` または `'` で囲みます。`print(H2O)` と書くと「H2Oという名前の変数を探して」という意味になり、エラーになります。`print("H2O")` が正解です。

## 4. f-string：文と数をきれいに並べて表示する

文字列の前に `f` をつけると、`{ }` の中に変数や計算を埋め込めます。これを **f-string** と呼びます。とても便利なので必ず使えるようにしましょう。

```python
name = "水"
formula = "H2O"
mass_water = 18.015

print(f"{name} ({formula}) の分子量は {mass_water} g/mol です")

# 小数点以下の桁数もそろえられる（:.2f は「小数第2位まで」）
print(f"約 {mass_water:.2f} g/mol")
```

出力:

```text
水 (H2O) の分子量は 18.015 g/mol です
約 18.02 g/mol
```

## 5. 化学で使う：モル計算をやってみる

ここまでを組み合わせて、化学の基本計算をプログラムにします。

**例題**: 水 36.0 g は何モルで、分子は何個あるか？

$$ \text{物質量 [mol]} = \frac{\text{質量 [g]}}{\text{モル質量 [g/mol]}} $$

```python
# --- 入力する値 ---
mass_water = 18.015     # 水のモル質量 [g/mol]
avogadro = 6.022e23     # アボガドロ定数 [個/mol]
sample_g = 36.0         # 手元にある水の質量 [g]

# --- 計算 ---
moles = sample_g / mass_water          # 物質量 [mol]
molecules = moles * avogadro           # 分子の個数 [個]

# --- 表示 ---
print(f"水 {sample_g} g は {moles:.3f} mol です")
print(f"分子はおよそ {molecules:.3e} 個あります")
```

出力:

```text
水 36.0 g は 1.998 mol です
分子はおよそ 1.203e+24 個あります
```

!!! tip "`:.3e` の意味"
    `e` は指数表記（`1.203e+24` は 1.203 × 10²⁴）。とても大きい／小さい数はこの形が読みやすいです。`.3` は有効数字3桁の意味です。

## 演習問題

**問1.** ブドウ糖（グルコース）$C_6H_{12}O_6$ のモル質量を計算して表示してください。
原子量は C = 12.011、H = 1.008、O = 15.999 とします。f-string を使って「グルコースのモル質量は ○○ g/mol です」と表示しましょう。

**問2.** 問1で求めたモル質量を使って、**グルコース 90.0 g が何モルか**を計算し、小数第3位まで表示してください。

**問3.** 問2のモル数から、**グルコース分子が何個あるか**を指数表記（`:.3e`）で表示してください。アボガドロ定数は `6.022e23` とします。

---

## 解答

??? success "問1 の解答"
    ```python
    mass_C = 12.011
    mass_H = 1.008
    mass_O = 15.999

    glucose = mass_C * 6 + mass_H * 12 + mass_O * 6
    print(f"グルコースのモル質量は {glucose:.3f} g/mol です")
    ```

    出力:
    ```text
    グルコースのモル質量は 180.156 g/mol です
    ```

??? success "問2 の解答"
    ```python
    glucose = 180.156        # 問1の結果
    sample_g = 90.0
    moles = sample_g / glucose
    print(f"グルコース {sample_g} g は {moles:.3f} mol です")
    ```

    出力:
    ```text
    グルコース 90.0 g は 0.500 mol です
    ```

    （ちょうど半モルですね。手計算とも一致します。）

??? success "問3 の解答"
    ```python
    moles = 0.500
    avogadro = 6.022e23
    molecules = moles * avogadro
    print(f"分子はおよそ {molecules:.3e} 個あります")
    ```

    出力:
    ```text
    分子はおよそ 3.011e+23 個あります
    ```
