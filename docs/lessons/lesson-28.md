## 1. モル濃度をまとめて計算

モル濃度 [mol/L] ＝ 物質量 [mol] ÷ 体積 [L]。複数の溶液をまとめて計算します。

```python
import numpy as np

moles = np.array([0.1, 0.25, 0.5])       # 物質量 [mol]
volume = np.array([1.0, 0.5, 2.0])       # 体積 [L]

molarity = moles / volume                 # 位置ごとに割る
print(molarity.round(4))
```

出力:

```text
[0.1  0.5  0.25]
```

3つの溶液の濃度が一度に求まりました。

---

## 2. 希釈の計算（C1V1 = C2V2）

「濃い溶液を薄める」計算です。$C_1 V_1 = C_2 V_2$ から、薄めた後の濃度 $C_2 = \dfrac{C_1 V_1}{V_2}$。

```python
import numpy as np

C1 = 1.0        # もとの濃度 [mol/L]
V1 = 10         # 取る量 [mL]
V2 = 100        # 薄めた後の全量 [mL]

C2 = C1 * V1 / V2
print(f"薄めた後の濃度: {C2} mol/L")
```

出力:

```text
薄めた後の濃度: 0.1 mol/L
```

1.0 mol/L を10倍に薄めて 0.1 mol/L。単位は mL どうしなら約分されるので、そのまま計算できます。

---

## 3. 希釈系列（段階希釈）を配列で

「2倍ずつ薄めていく」ような希釈系列は、配列で一気に作れます。

```python
import numpy as np

C0 = 1.0                              # はじめの濃度 [mmol/L]
factors = np.array([1, 2, 4, 8, 16]) # 希釈倍率（1, 2, 4, 8, 16倍）

series = C0 / factors
print(series.round(4))
```

出力:

```text
[1.     0.5    0.25   0.125  0.0625]
```

1倍（原液）から16倍希釈まで、5段階の濃度が一度に求まりました。検量線（第47回）用の標準溶液を作るときの計算そのものです。

!!! success "計算と可視化がつながる"
    この希釈系列の濃度と、対応する吸光度を測れば、第50回の**検量線**が描けます。第3部（NumPy）で作ったデータが、第5部（可視化）へとつながります。

!!! warning "AIの出力で確かめること"
    - 体積の単位：モル濃度 [mol/L] × 体積 のとき、体積が **L** になっているか（mL のままだと答えが1000倍になります）。
    - 結果が現実的か：100 mL の溶液に数百 g の塩が溶けることはありません（NaCl の溶解度は水 100 g に約 36 g）。

    - 1つを手計算で検算する：0.100 mol/L × 0.100 L × 58.44 g/mol = 0.5844 g。

## 演習問題

**問1.** 物質量 `moles = np.array([0.2, 0.6, 1.0])` mol と体積 `volume = np.array([2.0, 3.0, 4.0])` L から、モル濃度をまとめて計算してください。

**問2.** 0.5 mol/L の溶液を 5 mL 取り、50 mL に薄めたときの濃度を $C_2 = C_1 V_1 / V_2$ で計算してください。

**問3.** はじめの濃度 `C0 = 2.0` mol/L から、希釈倍率 `np.array([1, 3, 9, 27])`（3倍ずつ）で希釈系列を作ってください。

**問4.**（検証）次は AI が書いたコードです。NaCl（58.44 g/mol）で 0.050, 0.100, 0.200 mol/L の溶液を 100 mL ずつ調製するときに量り取る質量 [g] を求めたかったのですが、問題点を指摘し、直してください。

```python
import numpy as np

M_NaCl = 58.44                                  # モル質量 [g/mol]
target_C = np.array([0.050, 0.100, 0.200])      # 目標濃度 [mol/L]
V = 100                                         # 調製する体積 [mL]

mass_g = target_C * V * M_NaCl                  # 量り取る質量 [g]
print(mass_g.round(3))
```

出力:
```text
[ 292.2  584.4 1168.8]
```

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    moles = np.array([0.2, 0.6, 1.0])
    volume = np.array([2.0, 3.0, 4.0])
    print((moles / volume).round(4))
    ```

    出力:
    ```text
    [0.1  0.2  0.25]
    ```

??? success "問2 の解答"
    ```python
    C1, V1, V2 = 0.5, 5, 50
    C2 = C1 * V1 / V2
    print(f"{C2} mol/L")
    ```

    出力:
    ```text
    0.05 mol/L
    ```

??? success "問3 の解答"
    ```python
    import numpy as np
    C0 = 2.0
    factors = np.array([1, 3, 9, 27])
    print((C0 / factors).round(4))
    ```

    出力:
    ```text
    [2.     0.6667 0.2222 0.0741]
    ```

??? success "問4 の解答"
    **誤り**：モル濃度は mol/**L** なのに、体積を **mL** のまま掛けています。結果が1000倍になっています。

    **確かめ方**：100 mL の溶液に NaCl を 1 kg 以上溶かすことはできません（NaCl の溶解度は水 100 g に約 36 g）。手計算でも 0.100 mol/L × 0.100 L × 58.44 g/mol = 0.5844 g です。

    **修正**：

    ```python
    import numpy as np

    M_NaCl = 58.44                                  # モル質量 [g/mol]
    target_C = np.array([0.050, 0.100, 0.200])      # 目標濃度 [mol/L]
    V_mL = 100                                      # 調製する体積 [mL]
    V_L = V_mL / 1000                               # mL → L

    mass_g = target_C * V_L * M_NaCl                # 量り取る質量 [g]
    print(mass_g.round(3))
    ```

    出力:
    ```text
    [0.292 0.584 1.169]
    ```

- モル濃度 = 物質量 ÷ 体積。配列で複数溶液を一括計算。
- 希釈は $C_2 = C_1 V_1 / V_2$。
- 希釈系列は `C0 / 倍率の配列` で一気に作れる（検量線の標準溶液）。
