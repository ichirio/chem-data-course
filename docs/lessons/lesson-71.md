## 1. なぜ統計に R？

- **統計が標準装備**：t検定・分散分析・回帰などが、追加インストールなしで最初から使える。
- **統計グラフが美しい**：ggplot2 で論文品質の図を簡潔に描ける。
- **データ分析の文化**：統計学者・研究者が作ってきた言語で、手法が豊富。

!!! note "Python と R の使い分け"
    - **Python（第1〜6部）**：汎用・自動化・機械学習・分子（RDKit）。
    - **R（第7部）**：統計解析・きれいな統計グラフ・帳票（レポート）。

    どちらも優秀で、化学のデータ分析では**両方を使い分ける**のが現実的です。この教材が Python 主・R 副なのはそのためです。

## 2. R を起動して電卓として使う

ターミナルで `R` と打つと、R が起動します（`>` が表示される対話モード）。まず電卓のように使ってみましょう。

```r
1 + 2          # 3
10 / 4         # 2.5
2 ^ 10         # 1024（べき乗は ^）
sqrt(16)       # 4
```

出力:

```text
[1] 3
[1] 2.5
[1] 1024
[1] 4
```

!!! note "`[1]` の意味"
    R の出力の先頭に付く `[1]` は「結果の1個目」という印です。R は**すべてをベクトル（値の並び）**として扱うため、この番号が付きます（次回で詳しく）。

R を終了するには `q()` と入力します（`Save workspace? ` は `n` でOK）。

---

## 3. スクリプトとして実行する

対話モードのほか、`.R` ファイルにコードを書いて実行できます。`stats71.R` というファイルを作り、次を書きます。

```r
# 水の分子量を計算
mass_H <- 1.008          # R の代入は <- （矢印）
mass_O <- 15.999
water <- 2 * mass_H + mass_O
print(water)
```

VS Code の R 拡張（第1回）で実行するか、ターミナルで次を実行します。

```bash
Rscript stats71.R
```

出力:

```text
[1] 18.015
```

!!! warning "R の代入は `<-`"
    R では代入に **`<-`**（`<` と `-` の矢印）を使うのが伝統です（`=` も使えますが `<-` が標準）。`water <- 18` は「water に 18 を入れる」。Python の `=` にあたります。

## 演習問題

**問1.** R を起動し、電卓として (a) `15 * 3`、(b) `100 / 8`、(c) `3 ^ 4`、(d) `sqrt(144)` を計算してください。

**問2.** `stats71.R` を作り、二酸化炭素 CO₂ の分子量を `<-` を使って計算し、`print` で表示してください（C = 12.011、O = 15.999）。

**問3.** R で `log10(1000)` と `exp(1)` を計算してください（Python の math と同じ関数が、R では最初から使えます）。

---

## 解答

??? success "問1 の解答"
    ```r
    15 * 3        # [1] 45
    100 / 8       # [1] 12.5
    3 ^ 4         # [1] 81
    sqrt(144)     # [1] 12
    ```

??? success "問2 の解答"
    ```r
    mass_C <- 12.011
    mass_O <- 15.999
    co2 <- mass_C + 2 * mass_O
    print(co2)
    ```

    出力:
    ```text
    [1] 44.009
    ```

??? success "問3 の解答"
    ```r
    log10(1000)   # [1] 3
    exp(1)        # [1] 2.718282
    ```
    Python の `math.log10` `math.exp` にあたる関数が、R では `import` なしで使えます。

## この回のまとめ

- R は統計に特化した言語。検定・回帰・統計グラフが標準で強力。
- Python（汎用・分子・ML）と R（統計・帳票）を**使い分ける**。
- R の代入は `<-`。出力の `[1]` は「1個目」の印。
- 対話モード（`R`）と スクリプト（`Rscript ファイル.R`）で実行。
