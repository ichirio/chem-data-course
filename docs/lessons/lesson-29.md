## 1. 有名な落とし穴：0.1 + 0.2

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)     # 0.3 と等しい？
```

出力:

```text
0.30000000000000004
False
```

`0.1 + 0.2` が、ぴったり 0.3 になりません。これはバグではなく、**コンピュータが2進数で小数を扱う**ための、避けられない誤差です（どの言語でも起きます）。

!!! note "なぜ？"
    0.1 や 0.2 は、2進数では割り切れない無限小数になります（10進数の 1/3 = 0.333… のように）。有限桁で打ち切るため、ごくわずかな誤差が残ります。

## 2. 対処1：round で丸める

表示や比較の前に、意味のある桁で**丸める**のが基本です。

```python
result = 0.1 + 0.2
print(round(result, 2))         # 小数第2位に丸める
```

出力:

```text
0.3
```

!!! note "`round` は「四捨五入」ではない"
    Python の `round` は、ちょうど真ん中の値を**偶数側**に丸めます（`round(2.5)` → `2`、`round(3.5)` → `4`）。さらに小数は2進数で近似されているので、`round(0.125, 2)` → `0.12`、`round(2.675, 2)` → `2.67` のように、期待と違う結果になることがあります。レポートで厳密な四捨五入が必要なら、`decimal` モジュールを使います。
    ```python
    from decimal import Decimal, ROUND_HALF_UP
    print(Decimal("0.125").quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))   # 0.13
    ```

## 3. 対処2：np.isclose で「ほぼ等しい」を判定

小数どうしを `==` で比べるのは危険です。**「十分近いか」で判定**しましょう。NumPy の `np.isclose` が便利です。

```python
import numpy as np

print(0.1 + 0.2 == 0.3)              # 危険：False になる
print(np.isclose(0.1 + 0.2, 0.3))    # 安全：ほぼ等しいか
```

出力:

```text
False
True
```

!!! warning "小数の等値比較は `==` を避ける"
    測定値や計算結果の小数を「等しいか」判定するときは、`==` ではなく `np.isclose`（または「差が十分小さいか」）を使いましょう。これは数値計算の鉄則です。

## 4. 有効数字を意識した表示

化学では有効数字が大切です。f-string の書式で、桁数をそろえて表示します（第2回の復習）。

```python
molar_mass = 18.01528

print(f"{molar_mass:.3f}")     # 小数第3位まで
print(f"{molar_mass:.4g}")     # 有効数字4桁
print(f"{6.022e23:.3e}")       # 指数表記・小数点以下3桁（有効数字4桁）
```

出力:

```text
18.015
18.02
6.022e+23
```

!!! note "`:.3f` と `:.4g` の違い"
    - `:.3f` … **小数点以下**の桁数を指定（18.015）。
    - `:.4g` … **有効数字**の桁数を指定（18.02）。
    - `:.3e` … 指数表記で**小数点以下**の桁数を指定。有効数字は「指定した数＋1」桁（`:.3e` なら4桁：6.022e+23）。

    「小数第何位まで」なら `f`、「有効数字何桁」なら `g` を使い分けます。

!!! warning "`g` 書式は末尾の0を消す"
    `f"{0.500:.3g}"` は `0.5` と表示され、有効数字3桁の `0.500` になりません。末尾の0を残すには `#` を付けて `f"{0.500:#.3g}"` とします（→ `0.500`）。また `g` は、とても大きい／小さい数では自動で指数表記に切り替わります（`f"{123456:.3g}"` → `1.23e+05`）。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「2つの試料の水素イオン濃度 [H⁺]（1.0×10⁻⁹ と 5.0×10⁻⁹ mol/L）が同じとみなせるか判定し、pH を小数第2位まで表示するコードを書いてください。
    小数の比較には `np.isclose` を使い、**`rtol` と `atol` を明示**してください（濃度が 10⁻⁹ 程度と小さいことを考慮）。
    表示は f-string で、書式指定の意味（`f`・`e`・`g`）をコメントで説明してください。」

!!! warning "AIの出力で確かめること"
    - 小数どうしを `==` で比べていないか。
    - `np.isclose` の既定は `atol=1e-8` です。10⁻⁸ より小さい量（微量成分の mol/L、[H⁺] など）では、**桁が違う値でも True** になります。小さい量を比べるときは `atol=0` にして `rtol` で判定しているか確認する。
    - 書式の桁数：`.3e` は有効数字4桁、`.3g` は有効数字3桁で**末尾の0が消える**（9.00 → 9）、pH は `.2f` のように**小数点以下**で指定するのが普通。
    - `round` は偶数丸め（`round(2.5)` → 2）。四捨五入が前提の計算になっていないか。

## 演習問題

**問1.** `0.3 - 0.1` を計算して表示し、`0.2` とぴったり一致するか `==` で確かめてください。次に `np.isclose` でも判定して、結果の違いを見てください。

**問2.** 計算結果 `x = 1 / 3` を、(a) 小数第4位まで（`:.4f`）、(b) 有効数字3桁（`:.3g`）で表示してください。

**問3.** アボガドロ定数 `6.02214076e23` を、指数表記で有効数字4桁で表示してください（ヒント：`e` 書式の `.` の後の数は小数点以下の桁数です）。

**問4.**（検証）次は AI が書いたコードです。2つの試料の [H⁺] が同じとみなせるかを判定し、pH を小数第2位まで表示したかったのですが、問題点を指摘し、直してください。

```python
import numpy as np

H_a = 1.0e-9     # 試料A の [H+] [mol/L]
H_b = 5.0e-9     # 試料B の [H+] [mol/L]

if np.isclose(H_a, H_b):
    print("同じ濃度")
else:
    print("異なる濃度")
print(f"pH: {-np.log10(H_a):.3g}, {-np.log10(H_b):.3g}")
```

出力:
```text
同じ濃度
pH: 9, 8.3
```

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    print(0.3 - 0.1)                       # 0.19999999999999998
    print(0.3 - 0.1 == 0.2)                # False
    print(np.isclose(0.3 - 0.1, 0.2))      # True
    ```

    出力:
    ```text
    0.19999999999999998
    False
    True
    ```
    `==` では False ですが、`np.isclose` は「ほぼ等しい」を正しく True と判定します。

??? success "問2 の解答"
    ```python
    x = 1 / 3
    print(f"{x:.4f}")     # 0.3333
    print(f"{x:.3g}")     # 0.333
    ```

    出力:
    ```text
    0.3333
    0.333
    ```

??? success "問3 の解答"
    ```python
    print(f"{6.02214076e23:.3e}")
    ```

    出力:
    ```text
    6.022e+23
    ```
    有効数字4桁なら、小数点以下は3桁なので `:.3e` です（`:.4e` にすると `6.0221e+23` で有効数字5桁になります）。

??? success "問4 の解答"
    誤りは2か所です。

    1. **`np.isclose` の既定の許容誤差**：既定は `atol=1e-8`（差が 10⁻⁸ 以下なら「近い」）です。1.0×10⁻⁹ と 5.0×10⁻⁹ の差は 4×10⁻⁹ なので、濃度が5倍も違うのに True になってしまいます。小さい量を比べるときは `atol=0` にし、`rtol`（相対誤差）で判定します。
    2. **表示の書式**：`.3g` は有効数字3桁で、末尾の0を消すので 9.00 が `9` になります。pH は小数第2位までなら `.2f` です。

    **確かめ方**：pH が 9.00 と 8.30 で 0.7 も違うのに「同じ濃度」と出るのは矛盾しています。`abs(H_a - H_b)` を表示し、`atol` の 1e-8 と比べてみましょう。

    **修正**：

    ```python
    import numpy as np

    H_a = 1.0e-9     # 試料A の [H+] [mol/L]
    H_b = 5.0e-9     # 試料B の [H+] [mol/L]

    if np.isclose(H_a, H_b, rtol=1e-3, atol=0):   # 相対誤差 0.1% 以内なら同じ
        print("同じ濃度")
    else:
        print("異なる濃度")
    print(f"pH: {-np.log10(H_a):.2f}, {-np.log10(H_b):.2f}")
    ```

    出力:
    ```text
    異なる濃度
    pH: 9.00, 8.30
    ```

## この回のまとめ

- コンピュータの小数計算には、避けられない**微小な誤差**がある（`0.1+0.2≠0.3`）。
- 表示・比較の前に `round` で丸める。
- 小数の等値は `==` でなく **`np.isclose`** で判定。
- 有効数字は書式で：`:.3f`（小数位）/ `:.4g`（有効数字）/ `:.3e`（指数）。
