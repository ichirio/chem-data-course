# 第18回　デバッグの基礎：AIと一緒にバグを直す

!!! abstract "この回のゴール"
    - エラーメッセージ（トレースバック）を落ち着いて読む
    - `print` を使って原因を絞り込む
    - AI を上手に使ってバグを直す
    - 所要時間の目安: 60分

プログラムは必ず間違えます。大事なのは「間違えないこと」ではなく、**間違いを見つけて直せること**。これがデバッグです。

---

## 1. トレースバックは「最後の行」から読む

エラーが出ると、赤い文字（トレースバック）が表示されます。長く見えますが、読むべきは主に**一番下の行**です。

```python
masses = {"H": 1.008, "O": 15.999}
water = masses["H"] * 2 + masses["Na"]   # "Na" は辞書に無い
```

トレースバック（一部）:

```text
Traceback (most recent call last):
  File "lesson18.py", line 2, in <module>
    water = masses["H"] * 2 + masses["Na"]
KeyError: 'Na'
```

- 一番下 … **エラーの種類とメッセージ**（`KeyError: 'Na'` ＝「'Na' というキーが無い」）。
- その上 … エラーが起きた**場所**（`line 2`）と、問題の行。

「どこで・どんな理由で困ったか」が全部書いてあります。第10回で学んだエラーの種類（`KeyError`, `ValueError`…）が、ここで役立ちます。

---

## 2. print で原因を絞り込む

「結果がなぜかおかしい」ときは、**途中の値を print して確かめる**のが基本です。

```python
def average(values):
    total = 0
    for v in values:
        total += v
    return total / len(values)

data = [12.1, 12.3, 12.0]
print("total を確認:", sum(data))    # 期待する合計はいくつ？
print("件数を確認:", len(data))       # 割る数は合っている？
print("平均:", average(data))
```

出力:

```text
total を確認: 36.4
件数を確認: 3
平均: 12.133333333333333
```

「どこまで正しくて、どこから変か」を、値を見ながら切り分けます。頭で考えるより、**print して事実を見る**ほうが速いことが多いです。

!!! tip "一度に1か所ずつ変える"
    バグ探しでは、**一度に1か所だけ**変えて結果を見ます。あれこれ同時に変えると、何が効いたのか分からなくなります。

---

## 3. AI を上手に使う

エラーやバグは、AI（Claude / ChatGPT）に相談するのが今の時代の定石です。**うまく聞く**のがコツ。

!!! success "AIに伝えるべき3点"
    1. **やりたかったこと**（例：分子量を計算したい）
    2. **書いたコード**（該当部分をそのまま貼る）
    3. **エラーメッセージ全文**（トレースバックを丸ごとコピー）

    この3点があると、AIは的確に直してくれます。逆に「動きません」だけだと、AIも答えようがありません。

!!! warning "AIの答えは必ず検証する"
    AI の修正案を**そのまま貼って終わり**にせず、**自分で実行して確かめ、なぜ直ったのかを理解**しましょう。AIも間違えます。「AIに書かせて、自分で検証する」——これが第1回から言い続けている、AI時代でいちばん大事な姿勢です。

## 4. よくあるバグ（早見表）

| 症状 | よくある原因 |
|---|---|
| `NameError` | 変数名のタイプミス、定義前に使用 |
| `KeyError` | 辞書に無いキー（スペルミス・大文字小文字） |
| `TypeError` | 文字列と数を混ぜた（`float()`忘れ、第2回・第8回） |
| `IndexError` | リストの範囲外（0始まりを忘れた） |
| 結果が文字列の連結に | `input()` の値を `float()` し忘れ |
| 平均などがずれる | 割る数の間違い、欠損の扱い |

## 演習問題

**問1.** 次のコードはエラーになります。トレースバックの一番下を読んで、原因（どのエラー・何が悪い）を説明し、直してください。
```python
elements = ["H", "He", "Li"]
print(elements[3])
```

**問2.** 次の関数は、収率がなぜか文字列の連結になってしまいます。`print` で原因を確かめ、直してください。
```python
a = input("測定値1 > ")   # 例として "88.5" が入るとする
b = input("測定値2 > ")   # 例として "91.2"
print(a + b)              # 期待は 179.7 なのに…
```

**問3.** バグを AI に相談する練習です。問1のコードとエラーメッセージを、AI（Claude / ChatGPT）に「やりたいこと・コード・エラー全文」の3点で伝えて、直し方を聞いてみてください。得られた答えを自分でも検証しましょう。

---

## 解答

??? success "問1 の解答"
    エラーは `IndexError: list index out of range`。`elements` は3個（インデックス 0・1・2）しかないのに、`[3]` で4番目を指したのが原因です。
    ```python
    elements = ["H", "He", "Li"]
    print(elements[2])       # 最後の要素は index 2（"Li"）
    # または
    print(elements[-1])      # 末尾を指す書き方
    ```

??? success "問2 の解答"
    `input()` の戻り値は**文字列**なので、`a + b` は文字の連結（"88.5"+"91.2"="88.591.2"）になります。`float()` で数に変換してから足します（第2回・第8回）。
    ```python
    a = input("測定値1 > ")
    b = input("測定値2 > ")
    print("確認:", type(a))          # <class 'str'> ← 文字列だと分かる
    print(float(a) + float(b))       # 数に変換してから足す → 179.7
    ```

??? success "問3 の解答・確認ポイント"
    AI に次のように伝えると効果的です。
    > 「Pythonでリストの要素を表示したいのですが、`IndexError: list index out of range` が出ます。コードは `print(elements[3])`、リストは3要素です。原因と直し方を教えてください。」
    
    AI は「インデックスは0始まりなので最大は2」と説明してくれるはずです。答えを鵜呑みにせず、実際に `elements[2]` で動くことを自分で確かめましょう。
