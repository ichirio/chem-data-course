## 1. `input()`：ユーザーに入力してもらう

`input()` は、キーボードからの入力を受け取る命令です。**受け取った値は必ず文字列（str）**になるので、数として使うときは `float()` や `int()` で変換します。

```python
name = input("あなたの名前は？ > ")
print(f"こんにちは、{name} さん！")

mass_text = input("質量[g]を入力 > ")   # 文字列で入ってくる
mass = float(mass_text)                # 数（小数）に変換
print(f"入力された質量は {mass} g です")
```

実行例（`>` の後があなたの入力）:

```text
あなたの名前は？ > 太郎
こんにちは、太郎 さん！
質量[g]を入力 > 18.0
入力された質量は 18.0 g です
```

!!! warning "変換を忘れると計算がおかしくなる"
    `input()` の結果は文字列です。`"3" + "4"` は `"34"`（文字の連結）になってしまいます。数として足したいなら `float(...)` で変換してから。

## 3. 完成版コード（そのままコピペで動きます）

```python title="molar_calculator.py"
# ===== ミニ分子量電卓アプリ =====

# 原子量表
ATOMIC_MASS = {
    "H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999,
    "Na": 22.990, "S": 32.06, "Cl": 35.453,
}
AVOGADRO = 6.022e23

# 登録済みの分子（名前: 組成の辞書）
MOLECULES = {
    "水":        {"H": 2, "O": 1},
    "二酸化炭素": {"C": 1, "O": 2},
    "エタノール": {"C": 2, "H": 6, "O": 1},
    "グルコース": {"C": 6, "H": 12, "O": 6},
}


def molar_mass(composition):
    """組成の辞書からモル質量[g/mol]を返す"""
    total = 0.0
    for symbol, count in composition.items():
        total += ATOMIC_MASS[symbol] * count
    return total


def show_menu():
    """登録分子を番号つきで表示する"""
    print("\n--- 分子を選んでください ---")
    for i, name in enumerate(MOLECULES, start=1):
        print(f"  {i}. {name}")
    print("  0. おわる")


# ===== メインの流れ =====
names = list(MOLECULES)      # 分子名を番号で選べるようリスト化

print("ミニ分子量電卓へようこそ！")

while True:                                  # 「やめる」まで繰り返す
    show_menu()
    choice = input("番号を入力 > ")

    if choice == "0":
        print("おつかれさまでした！")
        break                                # ループを抜けて終了

    # 入力が 1〜分子数 の範囲の数字かチェック
    if not choice.isdecimal() or int(choice) < 1 or int(choice) > len(names):
        print("！ 正しい番号を入力してください")
        continue                             # やり直し

    # 選ばれた分子
    name = names[int(choice) - 1]            # 番号は1始まり、リストは0始まり
    comp = MOLECULES[name]
    mm = molar_mass(comp)
    print(f"\n【{name}】のモル質量は {mm:.3f} g/mol です")

    # 質量を入れてもらって、物質量と分子数を計算
    mass_text = input(f"{name} は何 g ありますか？（不要なら Enter）> ")
    if mass_text.strip() != "":
        mass = float(mass_text)
        n = mass / mm
        molecules = n * AVOGADRO
        print(f"  → {mass} g は {n:.3f} mol")
        print(f"  → 分子はおよそ {molecules:.3e} 個")
```

### 実行してみよう

ターミナルで `python molar_calculator.py` を実行します。対話の例:


## この長いコードの読み解き方

一度に全部理解できなくて大丈夫です。**部品ごと**に見ると簡単です。

1. `ATOMIC_MASS` / `MOLECULES` … データ（辞書）
2. `molar_mass()` / `show_menu()` … 部品（関数）
3. `while True:` の中 … メインの流れ（選ぶ → 計算 → 表示 → くり返す）

!!! tip "AIと一緒に読む"
    分からない行は、その行をコピーしてAI（Claude / ChatGPT）に「この行は何をしている？」と聞いてみましょう。**答えを写すのではなく、説明を読んで自分で納得する**のがコツです。

!!! example "AIへの頼み方（例）"
    次の Python アプリ `molar_calculator.py`（全文を貼り付け）の `MOLECULES` 辞書に、メタノール CH3OH と炭酸カルシウム CaCO3 を追加してください。
    組成は `{元素記号: 個数}` の辞書で、同じ元素は個数を合計して1つにまとめてください。
    `ATOMIC_MASS` に無い元素を使う場合は、原子量（IUPAC の値、小数第3位まで）も追加してください。
    変更後の `ATOMIC_MASS` と `MOLECULES` を全体で示し、何を追加したかを箇条書きで説明してください。それ以外の部分は変更しないでください。

!!! warning "AIの出力で確かめること"
    - 分子式と組成の辞書が合っているか。CH3OH は C 1・H 4・O 1 です（構造式の「H3」だけを拾って H を 3 にしていないか）。
    - 新しい元素（Ca など）が `ATOMIC_MASS` に追加されているか。無いと、その分子を選んだ瞬間に `KeyError: 'Ca'` でアプリが止まります。
    - 登録分子を全部 for で回して `molar_mass()` を計算し、既知の値と比べる（メタノール 32.042 g/mol、炭酸カルシウム 100.086 g/mol）。メニューから1つずつ選ぶより早く、全部を確認できます。
    - 番号入力のチェック（`isdigit()` または `isdecimal()`・範囲）や `break` / `continue` の位置など、頼んでいない部分が書き換えられていないか。
    - 質量の欄に `18g` などを入れたときの動き（今のままでは ValueError で止まる。対策は第10回）。

## 演習問題

**問1.** `MOLECULES` に、あなたの好きな分子を1つ追加してください。例：**アンモニア $NH_3$**（`{"N": 1, "H": 3}`）や **メタン $CH_4$**（`{"C": 1, "H": 4}`）。追加後にアプリを動かし、メニューに出ることを確認しましょう。

**問2.** `molar_mass()` に加えて、**質量とモル質量から物質量を返す関数** `moles(mass, mm)` を新しく定義し、メインの計算部分をその関数を使う形に書き換えてください（動きは同じでも、部品に分けると読みやすくなります）。

**問3.**（発展）アプリに「選んだ分子の**元素の種類の数**を表示する」機能を足してください。ヒント：組成の辞書 `comp` に対して `len(comp)` が元素の種類数になります。


**問4.**（検証）アプリにメタノールと炭酸カルシウムを追加するよう AI に頼んだところ、次のように書き換えられました（該当部分のみ）。このまま動かすと、どんな問題が起きるでしょうか。問題点を2つ指摘し、直してください。

```python
ATOMIC_MASS = {
    "H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999,
    "Na": 22.990, "S": 32.06, "Cl": 35.453,
}

MOLECULES = {
    "水":           {"H": 2, "O": 1},
    "二酸化炭素":    {"C": 1, "O": 2},
    "エタノール":    {"C": 2, "H": 6, "O": 1},
    "グルコース":    {"C": 6, "H": 12, "O": 6},
    "メタノール":    {"C": 1, "H": 3, "O": 1},   # AI が追加
    "炭酸カルシウム": {"Ca": 1, "C": 1, "O": 3},  # AI が追加
}
```

---

## 解答

??? success "問1 の解答"
    `MOLECULES` の辞書に行を足すだけです。
    ```python
    MOLECULES = {
        "水":        {"H": 2, "O": 1},
        "二酸化炭素": {"C": 1, "O": 2},
        "エタノール": {"C": 2, "H": 6, "O": 1},
        "グルコース": {"C": 6, "H": 12, "O": 6},
        "アンモニア": {"N": 1, "H": 3},   # 追加
        "メタン":     {"C": 1, "H": 4},   # 追加
    }
    ```
    追加した分子がメニュー（5番・6番）に表示されれば成功です。

??? success "問2 の解答"
    関数を1つ足し、メインの計算部分を置き換えます。
    ```python
    def moles(mass, mm):
        """質量[g]とモル質量[g/mol]から物質量[mol]を返す"""
        return mass / mm

    # メインの計算部分（該当箇所を置き換え）
    if mass_text.strip() != "":
        mass = float(mass_text)
        n = moles(mass, mm)              # 関数を使う形に
        molecules = n * AVOGADRO
        print(f"  → {mass} g は {n:.3f} mol")
        print(f"  → 分子はおよそ {molecules:.3e} 個")
    ```

??? success "問3 の解答"
    モル質量を表示した直後に1行足します。
    ```python
    mm = molar_mass(comp)
    print(f"\n【{name}】のモル質量は {mm:.3f} g/mol です")
    print(f"  （{len(comp)} 種類の元素からできています）")   # 追加
    ```
    例：グルコース `{"C":6, "H":12, "O":6}` なら `3 種類の元素` と表示されます。


??? success "問4 の解答"
    **確かめ方**：メニューから1つずつ選ぶ代わりに、登録分子を全部計算する確認用のコードを `ATOMIC_MASS`・`molar_mass()`・`MOLECULES` の後に書いて実行します。
    ```python
    for name, comp in MOLECULES.items():
        print(f"{name}: {molar_mass(comp):.3f} g/mol")
    ```

    出力（AI の書き換えのまま）:
    ```text
    水: 18.015 g/mol
    二酸化炭素: 44.009 g/mol
    エタノール: 46.069 g/mol
    グルコース: 180.156 g/mol
    メタノール: 31.034 g/mol
    Traceback (most recent call last):
      ...
    KeyError: 'Ca'
    ```

    **問題点1：メタノールの水素の数が違う。** CH3OH の H は CH3 の 3 個と OH の 1 個で合計 4 個です。メタノールのモル質量は 32.042 g/mol のはずなので、31.034 はおかしいと気づけます。

    **問題点2：原子量表に Ca が無い。** 炭酸カルシウムを選ぶと `KeyError: 'Ca'` でアプリが止まります。

    **修正版**：
    ```python
    ATOMIC_MASS = {
        "H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999,
        "Na": 22.990, "S": 32.06, "Cl": 35.453, "Ca": 40.078,
    }

    MOLECULES = {
        "水":           {"H": 2, "O": 1},
        "二酸化炭素":    {"C": 1, "O": 2},
        "エタノール":    {"C": 2, "H": 6, "O": 1},
        "グルコース":    {"C": 6, "H": 12, "O": 6},
        "メタノール":    {"C": 1, "H": 4, "O": 1},   # CH3OH = CH4O
        "炭酸カルシウム": {"Ca": 1, "C": 1, "O": 3},  # Ca を原子量表に追加済み
    }
    ```

    確認用コードの出力:
    ```text
    水: 18.015 g/mol
    二酸化炭素: 44.009 g/mol
    エタノール: 46.069 g/mol
    グルコース: 180.156 g/mol
    メタノール: 32.042 g/mol
    炭酸カルシウム: 100.086 g/mol
    ```
