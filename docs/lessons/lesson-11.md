## 1. import して使う

モジュールは `import` で読み込み、`モジュール名.機能名` で使います。

```python
import math

print(math.sqrt(16))     # 平方根 → 4.0
print(math.log10(1000))  # 常用対数（10を底）→ 3.0
print(math.exp(1))       # e^1 → 2.718...
print(math.pi)           # 円周率 → 3.14159...
```

出力:

```text
4.0
3.0
2.718281828459045
3.141592653589793
```

!!! note "いろいろな import の書き方"
    ```python
    import math                 # math.sqrt(...) と書く（おすすめ・どこの機能か明確）
    from math import sqrt, pi   # sqrt(...) と直接書ける
    import numpy as np          # 別名をつける（第3部で使う）
    ```

## 2. pH を計算する（対数の出番）

化学で対数といえば pH です。$\text{pH} = -\log_{10}[\text{H}^+]$。`math.log10` でそのまま書けます。

```python
import math

h = 1e-3                     # 水素イオン濃度 [mol/L]（= 1×10^-3）
pH = -math.log10(h)
print(f"[H+] = {h} のとき pH = {pH}")
```

出力:

```text
[H+] = 0.001 のとき pH = 3.0
```

逆に、pH から水素イオン濃度を求めるには $[\text{H}^+] = 10^{-\text{pH}}$。べき乗は `**` です。

```python
pH = 8.5
h = 10 ** (-pH)
pOH = 14 - pH               # 25 °C（Kw = 1.0×10^-14）のときだけ成り立つ
print(f"pH {pH} → [H+] = {h:.2e} mol/L, pOH = {pOH}")
```

出力:

```text
pH 8.5 → [H+] = 3.16e-09 mol/L, pOH = 5.5
```

## 3. アレニウスの式（指数関数）

反応速度定数の温度依存を表すアレニウスの式 $k = A\,e^{-E_a/RT}$ も、`math.exp` で書けます。

```python
import math

A = 1e13          # 頻度因子 [s^-1]（一次反応を想定）
Ea = 75000        # 活性化エネルギー [J/mol]
R = 8.314         # 気体定数 [J/(mol·K)]
T = 298           # 温度 [K]

k = A * math.exp(-Ea / (R * T))
print(f"速度定数 k = {k:.4f} s^-1")
```

出力:

```text
速度定数 k = 0.7132 s^-1
```

!!! tip "どんなモジュールがある？"
    `math`（数学）、`statistics`（統計）、`random`（乱数）、`datetime`（日時）、`os`（ファイル操作）… 標準ライブラリだけでも膨大です。「やりたいこと Python モジュール」で検索するか、AIに聞くと、たいてい既にある部品が見つかります。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「Python の標準ライブラリ `math` だけを使って、水素イオン濃度 [H+]（mol/L、例: 2.5e-5）から pH を計算する関数 `ph_from_h(h)` を書いてください。
    対数は常用対数（`math.log10`）を使うこと。h が 0 以下なら `ValueError` を出すこと。
    あわせて、アレニウスの式 k = A·exp(−Ea/RT) で速度定数を返す関数 `arrhenius(A, Ea_J_per_mol, T_K)` も書いてください。
    Ea は J/mol、T は K、R = 8.314 J/(mol·K) とし、引数名に単位を入れてください。」

!!! warning "AIの出力で確かめること"
    - 対数が `math.log10` になっているか。`math.log` は**自然対数**なので、[H+] = 1e-3 で pH が 3.0 ではなく 6.91 になります。`ph_from_h(1e-3)` が `3.0` になるかを必ず試す。
    - Ea と R の単位がそろっているか。Ea を kJ/mol（例: `75`）のまま R = 8.314 J/(mol·K) で割ると、指数がほぼ 0 になり k ≈ A になってしまいます。`print(Ea / (R * T))` が 298 K・75 kJ/mol で約 30 になるか確認する。
    - 温度が摂氏のまま使われていないか（`T = 25` ではなく `T = 298.15`）。
    - `pOH = 14 - pH` を使っていたら、25 °C 以外の温度で使われていないか。
    - 結果が化学的にありうる範囲か（強酸・強塩基の希薄溶液なら pH はおおむね 0〜14、温度を上げたら k は大きくなる）。

## 演習問題

**問1.** `math` を import して、(a) `math.sqrt(2)`、(b) `math.log10(100)`、(c) `math.exp(0)` を表示してください。

**問2.** 水素イオン濃度 `h = 2.5e-5` mol/L の溶液の pH を、`math.log10` を使って小数第2位まで計算してください。酸性・中性・塩基性のどれですか？

**問3.** アレニウスの式で、温度を `T = 310` K に上げたときの速度定数 k を計算してください（他の値は本文と同じ）。298 K のときと比べて、k は大きくなりますか小さくなりますか？

**問4.** 次は AI が書いたコードです。[H+] = 2.5×10⁻⁵ mol/L の pH（問2と同じ）と、298 K での速度定数（本文と同じ条件）を計算するつもりですが、結果がおかしくなっています。問題点を2つ指摘し、直してください。
```python
import math

h = 2.5e-5           # 水素イオン濃度 [mol/L]
pH = -math.log(h)
print(f"pH = {pH:.2f}")

A = 1e13             # 頻度因子 [s^-1]
Ea = 75              # 活性化エネルギー [kJ/mol]
R = 8.314            # 気体定数 [J/(mol·K)]
T = 298              # 温度 [K]
k = A * math.exp(-Ea / (R * T))
print(f"k = {k:.3e} s^-1")
```

出力:
```text
pH = 10.60
k = 9.702e+12 s^-1
```

---

## 解答

??? success "問1 の解答"
    ```python
    import math
    print(math.sqrt(2))     # 1.4142135623730951
    print(math.log10(100))  # 2.0
    print(math.exp(0))      # 1.0
    ```

??? success "問2 の解答"
    ```python
    import math
    h = 2.5e-5
    pH = -math.log10(h)
    print(f"pH = {pH:.2f}")
    ```

    出力:
    ```text
    pH = 4.60
    ```
    pH 4.60 は 7 より小さいので**酸性**です。

??? success "問3 の解答"
    ```python
    import math
    A, Ea, R = 1e13, 75000, 8.314
    k310 = A * math.exp(-Ea / (R * 310))
    print(f"k(310K) = {k310:.4f} s^-1")
    ```

    出力:
    ```text
    k(310K) = 2.3021 s^-1
    ```
    298 K では 0.7132 だったので、温度を上げると k は**大きく**なります（反応が速くなる）。わずか12 K の上昇で約3.2倍。温度の影響の大きさが分かります。

??? success "問4 の解答"
    **誤り1：`math.log` は自然対数（底 e）です。** pH は常用対数（底10）なので `math.log10` を使います。pH 10.60 は「塩基性」と読めてしまい、[H+] = 2.5×10⁻⁵ mol/L（酸性）と矛盾する——この**化学的な矛盾**で気づけます。

    **誤り2：Ea が kJ/mol なのに、R が J/(mol·K)。** 単位がそろっていないため `Ea / (R * T)` が約 0.03 になり、`exp(-0.03)` ≈ 1、つまり k ≈ A（10¹³ s⁻¹）という非現実的な値になりました。Ea を J/mol（75e3）に直します。`Ea / (R * T)` を print して、30 前後になるかで確かめられます。

    ```python
    import math

    h = 2.5e-5           # 水素イオン濃度 [mol/L]
    pH = -math.log10(h)  # 常用対数
    print(f"pH = {pH:.2f}")

    A = 1e13             # 頻度因子 [s^-1]
    Ea = 75e3            # 活性化エネルギー [J/mol]（75 kJ/mol を J に換算）
    R = 8.314            # 気体定数 [J/(mol·K)]
    T = 298              # 温度 [K]
    print(f"Ea/(RT) = {Ea / (R * T):.1f}")
    k = A * math.exp(-Ea / (R * T))
    print(f"k = {k:.3e} s^-1")
    ```

    出力:
    ```text
    pH = 4.60
    Ea/(RT) = 30.3
    k = 7.132e-01 s^-1
    ```
    pH は問2と、k は本文の 0.7132 s⁻¹ と一致しました。
