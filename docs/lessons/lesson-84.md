# 第84回　重回帰分析

!!! abstract "この回のゴール"
    - 複数の要因（説明変数）から結果を予測する重回帰を知る
    - `lm(y ~ x1 + x2)` を実行する
    - 各要因の効果と有意性を読む
    - 所要時間の目安: 60分
    - 使うテーマ：**温度と触媒量から収率を予測**

単回帰（第83回）は1つの要因でしたが、実際の実験では**複数の要因**が結果に影響します。それを同時に扱うのが**重回帰**です。

`stats84.R` を作りましょう。

```r
library(tidyverse)

# 収率を、温度と触媒量から説明する
d <- tibble(
  yield   = c(78, 85, 70, 80, 58, 66, 82, 75),
  temp    = c(80, 110, 80, 110, 80, 110, 80, 110),
  loading = c(2, 2, 1.5, 1.5, 1, 1, 2.5, 2.5)   # 触媒量
)
```

---

## 1. 重回帰を実行する

`lm(y ~ x1 + x2)` と、説明変数を `+` でつなぎます。

```r
fit <- lm(yield ~ temp + loading, data = d)
summary(fit)
```

出力（抜粋）:

```text
Coefficients:
            Estimate Std. Error t value Pr(>|t|)  
(Intercept)  40.4000    16.7107   2.418   0.0603 .
temp          0.1500     0.1561   0.961   0.3808  
loading      11.2000     4.1895   2.673   0.0442 *

Residual standard error: 6.624 on 5 degrees of freedom
Multiple R-squared:  0.6174,	Adjusted R-squared:  0.4644 
F-statistic: 4.035 on 2 and 5 DF,  p-value: 0.09052
```

読み方:

- **temp の Estimate 0.15（p = 0.38）**… 温度の効果。p > 0.05 なので、この範囲では**有意ではない**。
- **loading の Estimate 11.2（p = 0.044）**… 触媒量の効果。p < 0.05 で**有意**。触媒量を1増やすと収率が約11%上がる。
- **R² 0.62** … 2要因で収率の約62%を説明。

つまり「収率には触媒量が効いていて、温度の影響ははっきりしない」と読み取れます。複数要因の中で**どれが効くか**を切り分けられるのが重回帰の強みです。

---

## 2. 予測に使う

作ったモデルで、新しい条件の収率を予測できます。

```r
new_data <- tibble(temp = 100, loading = 2.0)
predict(fit, new_data)
```

`predict()` に新しい条件を渡すと、モデルが予測値を返します（実験計画の検討に使えます）。

!!! warning "重回帰の注意"
    - 説明変数どうしが強く相関している（多重共線性）と、係数が不安定になります。
    - 説明変数の数に対してデータが少ないと、過剰適合（第90回・機械学習でも扱う）に陥ります。今回は8点で2変数なので、あくまで練習用の小さな例です。

---

## 演習問題

**問1.** 本文の `d` で `lm(yield ~ temp + loading)` を実行し、`loading`（触媒量）の効果が有意か（p < 0.05 か）を確認してください。

**問2.** `predict()` を使って、`temp = 110, loading = 2.5` のときの収率を予測してください。

**問3.** 温度だけの単回帰 `lm(yield ~ temp, data = d)` を実行し、重回帰と比べて R² がどう変わるか見てください（要因を減らすと説明力はどうなる？）。

---

## 解答

??? success "問1 の解答"
    ```r
    summary(lm(yield ~ temp + loading, data = d))
    ```
    `loading` の行の `Pr(>|t|)` が 0.0442（< 0.05）なので**有意**。触媒量は収率に効いています。一方 `temp` は p = 0.38 で有意ではありません。

??? success "問2 の解答"
    ```r
    fit <- lm(yield ~ temp + loading, data = d)
    predict(fit, tibble(temp = 110, loading = 2.5))
    ```

    出力:
    ```text
        1 
    84.9 
    ```
    予測収率は約84.9%です。

??? success "問3 の解答"
    ```r
    summary(lm(yield ~ temp, data = d))
    ```
    温度だけのモデルでは R² が大きく下がります（温度単独では収率をほとんど説明できない）。触媒量を加えた重回帰の方が説明力が高い、と分かります。

---

## この回のまとめ

- 重回帰は `lm(y ~ x1 + x2)` で複数要因を同時に扱う。
- 各係数の `Pr(>|t|)` で、その要因が有意かを判断。
- `predict(fit, 新データ)` で予測。
- 多重共線性・過剰適合に注意（データ数に対して変数が多すぎない）。
