## 1. 機械学習とは

機械学習は、「データから規則を**自動で学ぶ**」技術です。人がルールを書く代わりに、たくさんの例からコンピュータがパターンを見つけます。

!!! example "化学での例"
    - **物性予測**：分子の構造（記述子）から、沸点・溶解度・毒性を予測する。
    - **活性予測（QSAR）**：分子の構造から、薬としての活性を予測する。
    - **材料スクリーニング**：候補材料の中から、望む性質を持つものを絞り込む。
    - **反応条件の最適化**：温度・触媒・溶媒などの条件から収率を予測する。

    「実験する前に、計算で当たりをつける」——これが機械学習の価値です。

---

## 2. 教師あり学習と教師なし学習

機械学習は、大きく2つに分かれます。

| 種類 | 何をする | 化学の例 |
|---|---|---|
| **教師あり学習** | 「入力 → 正解」の例から学び、未知の入力を予測 | 記述子 → 沸点（回帰）、記述子 → 活性/不活性（分類） |
| **教師なし学習** | 正解なしで、データの構造を見つける | 化合物を似た者どうしにグループ分け（クラスタリング）、次元削減（PCA） |

**教師あり**はさらに2つ：

- **回帰（regression）**：数値を予測する（沸点、収率、溶解度…）。
- **分類（classification）**：カテゴリを予測する（活性/不活性、溶ける/溶けない…）。

```mermaid
flowchart TB
    ML[機械学習] --> S[教師あり学習<br/>正解あり]
    ML --> U[教師なし学習<br/>正解なし]
    S --> R[回帰<br/>数値を予測]
    S --> C[分類<br/>カテゴリを予測]
    U --> CL[クラスタリング<br/>グループ分け]
    U --> D[次元削減<br/>PCA]
```

## 3. 機械学習の基本の流れ

どの手法も、おおむね次の流れです（第92回から実践します）。

1. **データを用意**：特徴量（入力）と、必要なら正解（目的変数）。
2. **訓練データとテストデータに分ける**：学習用と、性能確認用。
3. **モデルを学習させる**（`fit`）：訓練データからパターンを学ぶ。
4. **予測する**（`predict`）：新しいデータに適用。
5. **評価する**：予測がどれだけ当たるかを測る。

!!! warning "機械学習は魔法ではない"
    - **データの質が命**：偏った・少ない・汚いデータからは、良いモデルは作れません（第41回の前処理が効きます）。
    - **相関 ≠ 因果**（第52回・第83回）：予測できても「なぜ」を説明するとは限りません。
    - **外挿は危険**：学習した範囲の外では、予測は当てになりません（第85回の検量線と同じ）。分子でいえば、学習データと似ていない骨格・大きさの分子は「範囲の外」です（**適用範囲**、第100回）。
    - **学習に使ったデータで成績を測らない**：丸暗記でも満点になります。未知のデータでの成績の測り方は第95・96回で学びます。

    「AIが予測したから正しい」ではなく、**結果を検証する**姿勢が、ここでも大切です。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「化合物 200 個について、SMILES 列と IC50（単位 nM）列を持つ CSV があります。
    新しい化合物の活性を予測したいです。これは回帰・分類・クラスタリングのどれとして解くべきか、
    その理由、X（特徴量）と y（目的変数）に何を使うか、y を pIC50（= −log10(IC50 [M])）に変換すべきかを説明してください。
    コードはまだ不要です。性能をどう確かめるか（学習に使わないデータで測る方法）も提案してください。」

!!! warning "AIの出力で確かめること"
    - **y の型と手法が合っているか**：IC50 や沸点のような数値なら回帰、「活性/不活性」のようなカテゴリなら分類。数値を分類で解くと提案されたら、しきい値（例：IC50 < 1 µM を活性）と、その根拠が書かれているかを見る。
    - **X と y の取り違え**：「何から（X）何を（y）予測するか」を一文で言い直させ、自分の意図と一致するか確かめる。
    - **評価の方法**：「全データで学習して、同じデータで正解率を出す」は誤り。学習に使っていないデータで測る計画になっているか（第95・96回）。
    - **データ数と特徴量の数**：化合物 200 個に記述子 2000 個、のように特徴量のほうがずっと多い計画なら、過学習の危険を指摘できるか。
    - **適用範囲への言及**：「どんな化合物にも使える」と書いてあったら誤り。学習データに似た化合物に限る、という但し書きがあるか。

## 演習問題

**問1.** 次のそれぞれは、回帰・分類・クラスタリングのどれに当たりますか？ (a) 分子の構造から沸点（数値）を予測、(b) 化合物を「活性/不活性」に振り分ける、(c) 1000個の化合物を似た者どうしのグループに分ける。

**問2.** 「教師あり学習」と「教師なし学習」の違いを、自分の言葉で説明してください。

**問3.** あなたの興味のある化学分野で、機械学習が役立ちそうな場面を1つ考えてみてください（例：材料の物性予測、反応条件の最適化など）。

**問4.** 次は、あなたの依頼に対して AI が出した「解析の計画」です。問題点を2つ指摘し、直してください。

```text
目的：化合物 200 個の IC50（nM）のデータから、新しい化合物の活性を予測する。
1. IC50 は「活性の強さ」を表すので、分類問題として LogisticRegression で解く。
2. 200 個すべてでモデルを学習し、同じ 200 個で正解率を計算して性能を確認する。
3. 予測は、学習データに似た構造の化合物に限って使う。
```

---

## 解答

??? success "問1 の解答"
    - (a) 数値を予測 → **回帰**
    - (b) カテゴリ（活性/不活性）に振り分け → **分類**
    - (c) 正解なしでグループ分け → **クラスタリング**（教師なし）

??? success "問2 の解答"
    - **教師あり学習**：「入力と正解の組」を大量に与えて学習させ、未知の入力に対する答えを予測する（例：記述子と沸点の組から学び、新しい分子の沸点を予測）。
    - **教師なし学習**：正解を与えず、データそのものの構造（似ている・かたまり）を見つける（例：化合物を自動でグループ分け）。

??? success "問3 の解答（例）"
    「高分子の組成・構造から、引張強度やガラス転移温度を予測する」「触媒の記述子から反応収率を予測し、有望な触媒を絞り込む」など。**実験の前に計算で候補を絞る**場面が、機械学習の出番です。

??? success "問4 の解答"
    - **誤り1（手法の選び方）**：IC50 は数値なので、そのまま予測するなら**回帰**です。分類にしたいなら「IC50 < 1 µM を活性(1)」のような**しきい値を決めてから** 0/1 のラベルを作る必要があり、計画にはそれがありません。IC50 は桁で変わるので、回帰では pIC50（例：IC50 = 100 nM → pIC50 = 7.0）に変換するのが一般的です。
    - **誤り2（評価の方法）**：学習に使った 200 個で成績を測ると、丸暗記でも高得点になります。一部をテスト用に取り分ける（第95回）か、交差検証（第96回）で測ります。
    - 3 は正しい考え方です（適用範囲、第100回）。

    修正した計画:
    ```text
    1. IC50 [nM] を pIC50 に変換し、回帰モデルで予測する。
       （分類にする場合は、IC50 < 1 µM を活性とする、などの基準を先に決めて記録する）
    2. 学習に使わないテストデータ、または交差検証で性能を測る。
    3. 予測は、学習データに似た構造の化合物に限って使う。
    ```

## この回のまとめ

- 機械学習は、データからパターンを自動で学ぶ技術。
- **教師あり**（回帰・分類）と**教師なし**（クラスタリング・次元削減）。
- 基本の流れ：データ準備 → 分割 → 学習(fit) → 予測(predict) → 評価。
- データの質が命。外挿は危険。結果は必ず検証する。
