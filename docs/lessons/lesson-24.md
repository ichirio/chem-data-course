## 1. ブロードキャスト：スカラーと配列

配列に「1つの数（スカラー）」を掛けると、**全要素に自動で適用**されます。これがブロードキャストの基本です。

```python
import numpy as np

conc = np.array([0.1, 0.2, 0.5])    # mol/L

print(conc * 1000)      # mol/L → mmol/L（全要素を1000倍）
```

出力:

```text
[100. 200. 500.]
```

`conc * 1000` の `1000` が、自動的に全要素に配られています。第21回で見た「配列×スカラー」も、実はブロードキャストです。

## 2. 数式のベクトル化：理想気体の状態方程式

$PV = nRT$ を変形した $P = \dfrac{nRT}{V}$ を、**複数の温度についてまとめて**計算します。ループは不要です。

```python
import numpy as np

T = np.array([273, 298, 323])   # 温度 [K]（0℃, 25℃, 50℃）
n = 1.0                          # 物質量 [mol]
R = 0.0821                       # 気体定数 [L·atm/(mol·K)]
V = 1.0                          # 体積 [L]

P = n * R * T / V                # 温度の配列に一括で数式を適用
print(P.round(3))
```

出力:

```text
[22.413 24.466 26.518]
```

温度が3つあれば、圧力も3つ、まとめて求まります。`n`・`R`・`V`（スカラー）が、`T`（配列）に自動で対応（ブロードキャスト）しています。

!!! success "ベクトル化の威力"
    「温度を10℃刻みで100点」でも、コードは全く同じ。`T` を長くするだけで、100個の圧力が一瞬で計算されます。for ループを書かずに、数式をそのまま書けるのが NumPy の美しさです。第5部のグラフ用データも、こうして作ります。

## 3. 配列どうしのブロードキャスト

まずは身近な「1つの基準値との差」から。これは配列とスカラーの計算です。

```python
import numpy as np

measurements = np.array([12.1, 12.3, 12.0, 12.5])
reference = 12.2

print(measurements - reference)      # 各測定値と基準値の差
```

出力:

```text
[-0.1  0.1 -0.2  0.3]
```

各測定が基準からどれだけずれているかが、一括で分かります。

では、**形の違う配列どうし**はどうでしょう。長さ3と長さ4の1次元配列は、位置の対応がつかないのでエラーになります。

```python
import numpy as np
np.array([1, 2, 3]) + np.array([1, 2, 3, 4])
```

出力:

```text
ValueError: operands could not be broadcast together with shapes (3,) (4,) 
```

ブロードキャストが効くのは、**片方の長さが1の次元**があるときです。たとえば「縦に物質量、横に温度」を並べると、3×3 の圧力の表が一度に作れます。

```python
import numpy as np

T = np.array([273.15, 298.15, 323.15])   # 温度 [K]、形 (3,)
n = np.array([[0.5], [1.0], [2.0]])      # 物質量 [mol]、形 (3, 1)（縦長）
R, V = 0.08206, 1.0                      # [L·atm/(mol·K)], [L]

P = n * R * T / V                        # 形 (3, 1) と (3,) → (3, 3)
print(P.shape)
print(P.round(2))                        # 行: 物質量、列: 温度 [atm]
```

出力:

```text
(3, 3)
[[11.21 12.23 13.26]
 [22.41 24.47 26.52]
 [44.83 48.93 53.04]]
```

形が合わないとエラー、合えば自動で広がる——AI が書いたコードでは、`print(配列.shape)` で形を確かめる習慣をつけましょう。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「理想気体 1.0 mol を 22.4 L の容器に入れ、0, 25, 50 ℃ での圧力を kPa で求める NumPy コードを書いてください。
    温度は ℃ の配列で与えるので、**K に換算してから**式に入れてください。
    気体定数は R = 8.314 J/(mol·K) を使い、単位がどう kPa になるかをコメントで説明してください。for ループは使わないでください。」

!!! warning "AIの出力で確かめること"
    - 温度が **K** になっているか。℃ のまま入れると 0 ℃ で圧力 0 になります（`P[0]` を見ればすぐ分かる）。
    - 気体定数の単位と V・P の単位が合っているか：`0.08206 L·atm/(mol·K)` なら V は L・P は atm、`8.314 J/(mol·K)`（= 8.314 kPa·L/(mol·K)）なら V が L のとき P は kPa。
    - 目安の値と照合する：1 mol・22.4 L・273.15 K で約 1 atm（約 101 kPa）。
    - 形の違う配列どうしを計算するときは、`print(a.shape, b.shape, 結果.shape)` で、意図した形（例：`(3, 3)`）になっているか確認する。

## 演習問題

**問1.** 濃度の配列 `conc = np.array([0.05, 0.1, 0.25])` mol/L を、`* 1000` で mmol/L に変換してください。

**問2.** 理想気体の式で、温度 `T = np.array([250, 300, 350, 400])` K のときの圧力を計算してください（`n=2.0`, `R=0.0821`, `V=5.0`）。小数第3位まで表示しましょう。

**問3.** 測定値の配列 `data = np.array([98.5, 100.2, 99.8, 101.0, 97.9])` について、全要素から平均を引いた「偏差」を計算してください（ヒント：`data - data.mean()`）。

**問4.**（検証）次は AI が書いたコードです。1.0 mol の理想気体を 22.4 L の容器に入れたときの、0, 25, 50 ℃ での圧力 [kPa] を求めたかったのですが、問題点を指摘し、直してください。

```python
import numpy as np

T_C = np.array([0, 25, 50])     # 温度 [℃]
n, V = 1.0, 22.4                # [mol], [L]
R = 8.314                       # 気体定数 [J/(mol·K)]

P_kPa = n * R * T_C / V         # 圧力 [kPa]
print(P_kPa.round(2))
```

出力:
```text
[ 0.    9.28 18.56]
```

---

## 解答

??? success "問1 の解答"
    ```python
    import numpy as np
    conc = np.array([0.05, 0.1, 0.25])
    print(conc * 1000)
    ```

    出力:
    ```text
    [ 50. 100. 250.]
    ```

??? success "問2 の解答"
    ```python
    import numpy as np
    T = np.array([250, 300, 350, 400])
    n, R, V = 2.0, 0.0821, 5.0
    P = n * R * T / V
    print(P.round(3))
    ```

    出力:
    ```text
    [ 8.21   9.852 11.494 13.136]
    ```

??? success "問3 の解答"
    ```python
    import numpy as np
    data = np.array([98.5, 100.2, 99.8, 101.0, 97.9])
    print((data - data.mean()).round(3))
    ```

    出力:
    ```text
    [-0.98  0.72  0.32  1.52 -1.58]
    ```

??? success "問4 の解答"
    **誤り**：温度を **℃ のまま** 式に入れています。状態方程式の T は絶対温度 [K] です。

    **確かめ方**：0 ℃ で圧力が 0 kPa になるのは物理的にありえません。1 mol・22.4 L・0 ℃ なら約 101 kPa（約 1 atm）のはずです。

    なお、R = 8.314 J/(mol·K) は 8.314 kPa·L/(mol·K) と同じなので、V を L で入れれば P は kPa になります。**単位の組み合わせ自体は正しい**点も確認しておきましょう。

    **修正**：

    ```python
    import numpy as np

    T_C = np.array([0, 25, 50])     # 温度 [℃]
    T_K = T_C + 273.15              # 温度 [K]
    n, V = 1.0, 22.4                # [mol], [L]
    R = 8.314                       # 気体定数 [J/(mol·K)] = [kPa·L/(mol·K)]

    P_kPa = n * R * T_K / V         # 圧力 [kPa]
    print(P_kPa.round(2))
    ```

    出力:
    ```text
    [101.38 110.66 119.94]
    ```
