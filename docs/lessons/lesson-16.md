!!! abstract "この回のゴール"
    - コードを**少しずつ・対話的に**実行するスタイルを知る
    - VS Code の「セル実行」と Jupyter Notebook を使う
    - データ分析に向いた進め方を身につける
    - 所要時間の目安: 60分

これまではスクリプト（`.py`）を一気に実行してきました。データ分析では、**1行ずつ結果を見ながら**進めるほうが向いています。それを可能にするのが **Jupyter** の仕組みです。

!!! note "RStudio 経験者へ：対応するもの"
    R の RStudio で「1行ずつ実行して Environment で変数を確認」するあの感覚に近いのが、この Jupyter／セル実行です。変数が生き続け、途中結果を確かめながら進められます。

---

## 1. 2つの使い方

Python を対話的に使う方法は主に2つ。どちらも第1回で入れた拡張機能で使えます。

| 方法 | ファイル | 特徴 |
|---|---|---|
| **VS Code のセル実行** | 普通の `.py` に `# %%` を書く | スクリプトのまま、区切って実行できる |
| **Jupyter Notebook** | `.ipynb` | セルと結果・グラフが1つの文書に残る |

---

## 2. VS Code のセル実行（`# %%`）

`.py` ファイルの中に `# %%` と書くと、そこが**セルの区切り**になります。各セルの上に出る「Run Cell」を押すと、そのセルだけ実行されます。

（例では第4部で学ぶ pandas を使っていますが、ここではセル実行の雰囲気をつかめれば十分です。pandas は第1回でインストール済みです。）

```python
# %%
import pandas as pd
polymers = pd.DataFrame({
    "polymer": ["PE", "PP", "PS"],
    "tensile_MPa": [25, 35, 45],
})
polymers            # セルの最後の値は自動で表示される

# %%
polymers["tensile_MPa"].mean()   # 別セル。polymers はまだ生きている

# %%
polymers.describe()
```

- セル1でデータを作り、セル2で平均、セル3で要約…と**少しずつ**進められます。
- 一度実行した変数（`polymers`）は**メモリに残る**ので、次のセルでそのまま使えます。
- セルの最後に置いた式（`polymers`）は、`print` しなくても結果が表示されます（`# %%` の場合、結果は右側に開く「Interactive」ウィンドウに出ます）。

!!! tip "実行のショートカット"
    セル内で `Shift + Enter` を押すと「実行して次のセルへ」。試行錯誤がとても速くなります。

---

## 3. Jupyter Notebook（`.ipynb`）

`.ipynb` ファイルは、**コード・実行結果・グラフ・説明文**が1つの文書に残る形式です。VS Code で「新しいファイル → Jupyter Notebook」で作れます。

- **セル**にコードを書いて実行 → すぐ下に結果やグラフが表示される。
- **Markdown セル**に説明や見出しを書ける（この教材のような文章も）。
- 分析の過程がそのまま記録として残るので、**レポートや共有**に向きます。

!!! note "使い分けの目安"
    - **試行錯誤・探索** → `# %%` のセル実行が手軽。
    - **記録・レポート・共有** → Notebook（`.ipynb`）。
    - **完成した処理を繰り返し動かす** → 普通のスクリプト（`.py`）。

---

## 4. 対話的スタイルの心得

!!! success "少しずつ確かめる"
    データ分析では「読み込む → **中身を見る** → 少し処理する → **また見る**」の繰り返しが基本です。一気に長いコードを書かず、**1ステップごとに結果を確認**する。エラーもすぐ見つかり、理解も深まります。第4部・第5部の内容は、この対話的スタイルで進めると特に捗ります。

!!! warning "実行順序に注意：最後は「全部を上から実行」で確認"
    セルは好きな順に何度でも実行できるため、「セルを飛ばした」「同じセルを2回実行した」「セルを消したのに変数だけ残っている」といったことが起こります。画面上のコードと、メモリ上の変数の中身が食い違うのです。

    - 変数を上書きするセル（例: `yields = [y / 100 for y in yields]`）は、2回実行すると2回割られます。**元のデータは上書きせず、新しい名前に入れる**のが安全です。
    - 分析が終わったら、Notebook なら「Restart（カーネルの再起動）→ Run All（すべて実行）」、`# %%` なら Interactive Window を再起動して上から順に実行し、同じ結果になるか確かめましょう。

## AIに任せるときの指示と確認

!!! example "AIへの頼み方（例）"
    「VS Code の `# %%` セル形式で、収率データ `[88.5, 91.2, 90.0]`（単位 %）を分析する .py ファイルを書いてください。
    セル1でデータ作成、セル2で割合（0〜1）への変換、セル3で平均の表示、と分けてください。
    どのセルを何回実行しても結果が変わらないように、元のリストは上書きせず新しい変数名に入れてください。」

!!! warning "AIの出力で確かめること"
    - 同じ変数を上書きするセル（`x = x / 100` や `yields = [y / 100 for y in yields]`）がないか。あると、そのセルを2回実行しただけで値が変わります。
    - セルの順番どおりに依存しているか。後ろのセルで定義した変数を前のセルで使っていないか。
    - 最後に「カーネル再起動 → 上から全部実行」をして、途中で見た結果と同じになるか。ならなければ、隠れた状態（古い変数）に頼っていた証拠です。
    - 表示のラベルと単位が中身と一致しているか（割合 0.9 を「0.9 %」と表示していないか）。

## 演習問題

**問1.** VS Code で `explore.py` を作り、`# %%` を使って2つのセルに分けてください。セル1で `import pandas as pd` とデータ作成、セル2でそのデータの `describe()` を実行し、セルごとに結果が出ることを確認しましょう。

**問2.** セル1を実行した後、セル2で「セル1で作った変数がそのまま使える」ことを確認してください（変数が生き続けること）。

**問3.** VS Code で新しい Jupyter Notebook（`.ipynb`）を作り、Markdown セルに見出しを1つ、コードセルに簡単な計算（例：水の分子量）を書いて実行してみてください。

**問4.** 次は AI が書いた `# %%` セル形式のコードです。上から1回ずつ実行すると `平均収率: 0.9 %` と表示され、セル2をもう一度実行してからセル3を実行すると `平均収率: 0.0 %` になりました。問題点を2つ指摘し、直してください。
```python
# %%
yields = [88.5, 91.2, 90.0]          # 収率 [%]

# %%
yields = [y / 100 for y in yields]   # % → 割合

# %%
print(f"平均収率: {sum(yields) / len(yields):.1f} %")
```

---

## 解答

??? success "問1・問2 の解答"
    ```python
    # %%
    import pandas as pd
    df = pd.DataFrame({"polymer": ["PE", "PP", "PS"], "tensile_MPa": [25, 35, 45]})
    df

    # %%
    df.describe()      # セル1の df がそのまま使える（変数が生きている）
    ```

    セル2の出力:
    ```text
           tensile_MPa
    count          3.0
    mean          35.0
    std           10.0
    min           25.0
    25%           30.0
    50%           35.0
    75%           40.0
    max           45.0
    ```

    セル1を実行 → 表が表示。セル2を実行 → 要約統計が表示。`df` を作り直さなくても使えるのがセル実行の利点です。

??? success "問3 の解答・確認ポイント"
    Notebook で、Markdown セルに `# 私の最初のノートブック` などと書いて実行すると見出しになります。コードセルに
    ```python
    mass = 2 * 1.008 + 15.999
    print(f"水の分子量: {mass:.3f}")
    ```
    と書いて実行すると、すぐ下に `水の分子量: 18.015` と出れば成功です。コードと結果と説明が1枚に残ります。

??? success "問4 の解答"
    **誤り1：セル2が元の変数 `yields` を上書きしています。** そのため、セル2を実行するたびに値がさらに 1/100 になります（2回目で `[0.00885, 0.00912, 0.009000000000000001]`）。セル実行では同じセルを何度も実行しがちなので、**元データは上書きせず、新しい名前に入れます**。

    **誤り2：セル3は割合（0〜1）を平均しているのに「%」と表示しています。** 1回だけ実行したときの `0.9 %` は、本当は「0.9（= 90 %）」です。単位のラベルと中身がずれていました。

    ```python
    # %%
    yields_pct = [88.5, 91.2, 90.0]          # 収率 [%]（元データは上書きしない）

    # %%
    yield_frac = [y / 100 for y in yields_pct]   # 割合（0〜1）。新しい名前に入れる
    print(yield_frac)

    # %%
    mean_pct = sum(yields_pct) / len(yields_pct)
    print(f"平均収率: {mean_pct:.1f} %")
    ```

    出力:
    ```text
    [0.885, 0.912, 0.9]
    平均収率: 89.9 %
    ```
    どのセルを何回実行し直しても同じ結果になります。最後に「上から全部実行」して確かめましょう。
