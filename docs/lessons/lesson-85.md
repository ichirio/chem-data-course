# 第85回　検量線と最小二乗法

!!! abstract "この回のゴール"
    - 回帰で検量線を作る
    - 未知試料の吸光度から**濃度を逆算**する
    - 決定係数で検量線の質を評価する
    - 所要時間の目安: 60分
    - 使うテーマ：**吸光光度法による定量分析**

分析化学の実務そのもの——標準溶液で**検量線**を作り、未知試料の濃度を求めます。第83回の回帰を応用します。

`stats85.R` を作りましょう。

```r
library(tidyverse)

# 標準溶液の濃度と吸光度
cal <- tibble(
  conc = c(0, 2, 4, 6, 8, 10),
  absb = c(0.02, 0.21, 0.40, 0.59, 0.80, 0.99)
)
```

---

## 1. 検量線（回帰直線）を作る

```r
fit <- lm(absb ~ conc, data = cal)
coef(fit)          # 係数（切片と傾き）
```

出力:

```text
(Intercept)        conc 
 0.01523810  0.09728571 
```

検量線は **吸光度 = 0.09729 × 濃度 + 0.01524**。`coef(fit)` で切片と傾きを取り出せます。

決定係数も確認します。

```r
summary(fit)$r.squared      # R^2
```

出力:

```text
[1] 0.9997471
```

R² ≈ 0.9997。ほぼ完璧に直線に乗っており、検量線として信頼できます。

---

## 2. 未知試料の濃度を逆算する

未知試料の吸光度を測ったら、検量線を逆に使って濃度を求めます。
吸光度 = 傾き × 濃度 + 切片 を変形して、**濃度 = (吸光度 − 切片) ÷ 傾き**。

```r
co <- coef(fit)
intercept <- co[1]
slope <- co[2]

unknown_abs <- 0.5                          # 未知試料の吸光度
unknown_conc <- (unknown_abs - intercept) / slope

cat("未知試料の濃度:", round(unknown_conc, 3), "mM\n")
```

出力:

```text
未知試料の濃度: 4.983 mM
```

吸光度0.5の未知試料は、約4.98 mM と求まりました。これが吸光光度法による定量の基本原理です。

!!! tip "`predict` は逆向きには使えない"
    `predict(fit, ...)` は「濃度 → 吸光度」を計算する関数で、吸光度から濃度を直接は求められません。また `approx()` は測定点を折れ線でつなぐ補間で、回帰直線とは別物です。直線の検量線なら、上のように式を変形するのが最も確実で分かりやすい方法です。逆算した濃度の不確かさまで求めたい場合は、`investr` パッケージの `calibrate()` などの専用関数を使います。

---

## 3. 検量線を評価する観点

!!! note "良い検量線の条件"
    - **R² が 0.99 以上**（直線性の目安。ただし R² が高くても曲がっていることはあるので、R² だけで判断しない）。
    - **残差にパターンがない**：`resid(fit)` を見て、濃度とともに系統的に正→負→正のように変化していないか確認する（本例は ±0.009 以内でランダム）。
    - **測定範囲内**で使う（外挿＝範囲外の予測は危険）。未知試料の吸光度が、標準の範囲内に収まっている。
    - **定量下限より上**で使う（下の LOD/LOQ）。

    範囲外（例：吸光度2.0）を無理に逆算すると、大きな誤差が出ます。高濃度では Lambert–Beer の直線性が崩れることもあります。検量線は「作った範囲の中で使う」のが鉄則で、範囲外なら試料を希釈して測り直します。

!!! note "検出下限（LOD）と定量下限（LOQ）"
    低濃度側の限界も確認します。よく使われる目安は、回帰の残差標準偏差 s と傾き b から LOD = 3.3 s / b、LOQ = 10 s / b です（ブランクの繰り返し測定の標準偏差を使う方法もあります）。

    ```r
    s <- summary(fit)$sigma
    lod <- 3.3 * s / slope
    loq <- 10 * s / slope
    cat("LOD:", round(lod, 2), "mM  LOQ:", round(loq, 2), "mM\n")
    ```

    出力:
    ```text
    LOD: 0.22 mM  LOQ: 0.67 mM
    ```

    この検量線では、およそ 0.67 mM 未満の濃度は「定量値」として報告できません。

## 演習問題

**問1.** 本文の検量線 `fit` の傾きと切片を `coef()` で取り出し、決定係数 R² を `summary(fit)$r.squared` で表示してください。

**問2.** 吸光度が **0.35** の未知試料の濃度を、検量線から逆算してください（濃度 = (吸光度 − 切片) ÷ 傾き）。

**問3.** 別の検量線データ `conc2 <- c(0, 5, 10, 15, 20)`、`absb2 <- c(0.01, 0.12, 0.25, 0.36, 0.49)` で回帰し、吸光度0.30の試料の濃度を求めてください。

---

## 解答

??? success "問1 の解答"
    ```r
    coef(fit)
    summary(fit)$r.squared
    ```

    出力:
    ```text
    (Intercept)        conc 
     0.01523810  0.09728571 
    [1] 0.9997471
    ```

??? success "問2 の解答"
    ```r
    co <- coef(fit)
    conc <- (0.35 - co[1]) / co[2]
    cat(round(conc, 3), "mM\n")
    ```

    出力:
    ```text
    3.441 mM
    ```

??? success "問3 の解答"
    ```r
    fit2 <- lm(absb2 ~ conc2)
    co2 <- coef(fit2)
    conc <- (0.30 - co2[1]) / co2[2]
    cat(round(conc, 2), "mM\n")
    ```

    出力:
    ```text
    12.25 mM
    ```

## この回のまとめ

- 検量線は `lm(absb ~ conc)` で作り、`coef()` で傾き・切片を取り出す。
- 未知試料は **濃度 = (吸光度 − 切片) ÷ 傾き** で逆算。
- R² ≥ 0.99 は目安の一つ。残差のパターンも確認し、**LOQ 以上・測定範囲内で使う**（外挿は危険）。
- これが吸光光度法による定量分析の基本原理。
