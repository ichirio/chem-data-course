# 第79回　仮説検定の考え方

!!! abstract "この回のゴール"
    - 仮説検定の考え方（帰無仮説・p値）を理解する
    - 有意水準の意味を知る
    - 「偶然か、意味のある差か」を判断する枠組みをつかむ
    - 所要時間の目安: 60分

「触媒Aの方が収率が高い」——それは**本当の差**でしょうか、それとも**たまたま**でしょうか。これを判断するのが**仮説検定**です。実験科学の心臓部です。

---

## 1. 仮説検定の枠組み

検定は、少し回りくどい論理で進みます。

1. **帰無仮説（H₀）を立てる**：「差はない」と仮定する（例：AとBの平均は同じ）。
2. **データを取る**：実際に測定する。
3. **p値を計算する**：「もし本当に差がないなら、これほどの差が偶然に出る確率」を求める。
4. **判断する**：p値が十分小さければ「偶然とは考えにくい」→ 帰無仮説を棄却し、**差がある**と結論。

!!! note "なぜ「差がない」から始めるのか"
    「差がある」を直接証明するのは難しいので、**「差がない」と仮定して矛盾を導く**（背理法に似た）論法を取ります。「差がないと考えると、こんな珍しいことが起きたことになる。それは変だ。だから差がある」という流れです。

---

## 2. p値と有意水準

- **p値**：帰無仮説（差がない）が正しいと仮定したときに、観測された差以上のことが起こる確率。
- **有意水準（α）**：判断の基準。慣例的に **0.05（5%）** を使う。
- **p < 0.05 なら「有意差あり」**（偶然では起きにくい＝意味のある差）と判断する。

```text
p < 0.05  → 帰無仮説を棄却 → 「有意差あり」
p ≥ 0.05  → 棄却できない   → 「有意差があるとは言えない」
```

!!! warning "p値の誤解に注意"
    - p値は「差が偶然である確率」ではありません（正確には「差がないと仮定したときにデータが出る確率」）。
    - **p ≥ 0.05 は「差がない証明」ではありません**（「差があるとは言えない」だけ）。
    - **有意差 ≠ 大きな差・重要な差**。サンプルが多いと小さな差でも有意になります。統計的有意性と実質的な重要性は別物です。

---

## 3. どの検定を使う？（次回以降の地図）

比べたいものに応じて、検定を使い分けます。

| 状況 | 検定 | 回 |
|---|---|---|
| 2群の平均を比べる | **t検定** | 第80回 |
| 3群以上の平均を比べる | **分散分析（ANOVA）** | 第81回 |
| カテゴリの偏りを調べる | **カイ二乗検定** | 第82回 |
| 2量の関係を調べる | **相関・回帰** | 第83回 |

R では、これらがすべて1行の関数（`t.test`, `aov`, `chisq.test`, `cor.test`, `lm`）で実行でき、p値まで自動で出ます。次回から実際に使っていきます。

!!! success "検定は「主張の裏付け」"
    「触媒Aが優れている」と論文で主張するには、検定による裏付けが求められます。R を使えば、実験データから客観的な結論を、手早く正しく導けます。

## 演習問題

**問1.** 次の文の p値は、有意水準0.05で「有意差あり」と判断できますか？ (a) p = 0.03、(b) p = 0.12、(c) p = 0.001。

**問2.** 「p = 0.20 だったので、2つの触媒には差がないことが証明された」——この文の何が誤りか説明してください。

**問3.** 次のそれぞれで、どの検定が適切か答えてください：(a) 2つの溶媒での収率の平均を比べる、(b) 4種類の触媒の収率を比べる、(c) 濃度と吸光度の関係を調べる。

---

## 解答

??? success "問1 の解答"
    - (a) p = 0.03 < 0.05 → **有意差あり**
    - (b) p = 0.12 ≥ 0.05 → 有意差があるとは言えない
    - (c) p = 0.001 < 0.05 → **有意差あり**（かなり強い証拠）

??? success "問2 の解答"
    「差がない**ことが証明された**」が誤りです。p ≥ 0.05 は「差があるとは言えない」だけで、「差がないことの証明」ではありません。差が本当にないのか、単にデータが足りず検出できなかったのかは区別できません。「差があるとは言えなかった」が正しい表現です。

??? success "問3 の解答"
    - (a) 2群の平均 → **t検定**（第80回）
    - (b) 3群以上の平均 → **分散分析（ANOVA）**（第81回）
    - (c) 2量の関係 → **相関・回帰**（第83回）

---

## この回のまとめ

- 検定は「差がない（帰無仮説）」と仮定し、p値で矛盾を調べる。
- p < 0.05 で「有意差あり」（有意水準0.05が慣例）。
- p ≥ 0.05 は「差がない証明」ではない。有意差 ≠ 重要な差。
- 状況に応じて t検定・ANOVA・カイ二乗・回帰を使い分ける。
