## 1. 比較：True か False か

プログラムは「はい／いいえ」で枝分かれします。まず値を比べてみましょう。答えは `True`（真）か `False`（偽）で返ります。

```python
pH = 3.0

print(pH < 7)     # 7より小さい？ → True
print(pH == 7)    # 7と等しい？   → False
print(pH > 7)     # 7より大きい？ → False
print(pH != 7)    # 7と違う？     → True
```

出力:

```text
True
False
False
True
```

| 記号 | 意味 |
|---|---|
| `==` | 等しい（`=` は代入なので**2つ重ねる**） |
| `!=` | 等しくない |
| `<` `>` | より小さい・より大きい |
| `<=` `>=` | 以下・以上 |

!!! warning "`=` と `==` は別物"
    `pH = 7` は「pHに7を入れる」（代入）。`pH == 7` は「pHは7ですか？」（比較）。**比較は必ず `==`** です。よくある間違いなので気をつけましょう。

## 2. if / else：条件で処理を分ける

`if` は「もし〜なら」。条件が `True` のときだけ、下の字下げした部分を実行します。

```python
pH = 3.0

if pH < 7:
    print("この溶液は酸性です")
else:
    print("この溶液は酸性ではありません")
```

出力:

```text
この溶液は酸性です
```

!!! note "書き方のきまり"
    - `if 条件:` の行末に**コロン `:`** をつける。
    - その下は**半角スペース4つで字下げ**（前回のfor と同じ）。字下げした範囲が「if の中身」です。

---

## 3. elif：3つ以上に枝分かれ

酸性・中性・塩基性の**3通り**に分けたいときは、`elif`（「そうでなくて、もし〜なら」）を使います。上から順に判定され、最初に当てはまった1つだけが実行されます。

```python
pH = 8.5

if pH < 7:
    print("酸性です")
elif pH == 7:
    print("中性です")
else:
    print("塩基性です")
```

出力:

```text
塩基性です
```

`elif` は何個でも並べられます。より細かく分けてみましょう。

```python
pH = 2.0

if pH < 3:
    print("強い酸性")
elif pH < 7:
    print("弱い酸性")
elif pH == 7:
    print("中性")
elif pH < 11:
    print("弱い塩基性")
else:
    print("強い塩基性")
```

出力:

```text
強い酸性
```

!!! tip "順番が大事"
    `elif` は上から順に調べ、**最初に True になった所で止まります**。範囲で分けるときは「狭い方・小さい方から」書くのがコツです。

## 4. and / or / not：条件を組み合わせる

「AかつB」「AまたはB」を表すのが `and` / `or`、「〜でない」が `not` です。

```python
temperature = 25    # 温度 [℃]
pH = 6.5

# 温度が 20〜30℃ の範囲内か（かつ）
if temperature >= 20 and temperature <= 30:
    print("室温の範囲内です")

# 酸性か塩基性か（＝中性でない）
if pH < 7 or pH > 7:
    print("中性ではありません")
```

出力:

```text
室温の範囲内です
中性ではありません
```

!!! note "範囲はまとめて書ける"
    `20 <= temperature <= 30` のように、数学と同じ書き方もできます（Pythonの便利な機能）。
    ```python
    if 20 <= temperature <= 30:
        print("室温の範囲内です")
    ```

## 5. まとめ：pH判定プログラム

ここまでを1つにまとめます。判定する pH を変えて、出力がどう変わるか試してみましょう。

```python
pH = 5.5

print(f"pH = {pH} の溶液は…")

if pH < 7:
    print("  → 酸性です")
elif pH == 7:
    print("  → 中性です")
else:
    print("  → 塩基性です")

# おまけ：強さも表示
if pH < 3 or pH > 11:
    print("  → しかも強いので取り扱い注意！")
```

出力:

```text
pH = 5.5 の溶液は…
  → 酸性です
```

## 演習問題

**問1.** 変数 `pH` に好きな値を入れ、「酸性／中性／塩基性」を判定して表示するプログラムを書いてください（`if`・`elif`・`else` を使う）。

**問2.** 水の状態を温度で判定しましょう。変数 `temp`（℃）に対して、`0` 未満なら「氷（固体）」、`0` 以上 `100` 未満なら「水（液体）」、`100` 以上なら「水蒸気（気体）」と表示してください（1気圧を仮定）。

**問3.** ある元素記号 `element` が**ハロゲン**かどうかを判定してください。ハロゲンのリスト `["F", "Cl", "Br", "I"]` を作り、`if element in halogens:` を使って「◯はハロゲンです／ではありません」と表示しましょう。

---

## 解答

??? success "問1 の解答"
    ```python
    pH = 9.2

    if pH < 7:
        print(f"pH {pH}：酸性です")
    elif pH == 7:
        print(f"pH {pH}：中性です")
    else:
        print(f"pH {pH}：塩基性です")
    ```

    出力（pH = 9.2 のとき）:
    ```text
    pH 9.2：塩基性です
    ```

??? success "問2 の解答"
    ```python
    temp = 25

    if temp < 0:
        print(f"{temp}℃：氷（固体）")
    elif temp < 100:
        print(f"{temp}℃：水（液体）")
    else:
        print(f"{temp}℃：水蒸気（気体）")
    ```

    出力（25℃ のとき）:
    ```text
    25℃：水（液体）
    ```

    ポイント：`elif temp < 100` の時点で「0未満」はすでに除かれているので、「0以上100未満」を自動的に表せます。

??? success "問3 の解答"
    ```python
    halogens = ["F", "Cl", "Br", "I"]
    element = "Cl"

    if element in halogens:
        print(f"{element} はハロゲンです")
    else:
        print(f"{element} はハロゲンではありません")
    ```

    出力（"Cl" のとき）:
    ```text
    Cl はハロゲンです
    ```

    `in` は「リストの中に含まれるか」を True / False で返します。とても便利なので覚えておきましょう。
