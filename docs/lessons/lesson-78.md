# 第78回　正規分布と確率

!!! abstract "この回のゴール"
    - 正規分布とは何かを知る
    - `dnorm` `pnorm` `qnorm` `rnorm` を使う
    - 「平均±標準偏差」に入る確率を求める
    - 所要時間の目安: 60分
    - 使うテーマ：**測定誤差の分布**

多くの測定誤差は**正規分布**（釣鐘型）に従います。統計的検定の土台となる、最重要の分布です。

`stats78.R` を作りましょう。

---

## 1. 正規分布の4つの関数

R には正規分布を扱う関数が揃っています（`norm` の前の文字で機能が変わります）。

| 関数 | 意味 |
|---|---|
| `dnorm(x)` | 確率密度（その点の高さ） |
| `pnorm(x)` | 累積確率（x 以下になる確率） |
| `qnorm(p)` | 分位点（確率 p に対応する x） |
| `rnorm(n)` | 正規分布に従う乱数を n 個 |

```r
pnorm(0)        # 平均(0)以下になる確率 → 0.5
pnorm(1.96)     # 1.96以下になる確率
qnorm(0.975)    # 上側2.5%点（1.96になるはず）
```

出力:

```text
[1] 0.5
[1] 0.9750021
[1] 1.959964
```

`pnorm(1.96) ≈ 0.975`、`qnorm(0.975) ≈ 1.96`——この 1.96 は、95%信頼区間や検定で頻繁に出てくる重要な値です。

---

## 2. 「平均 ± 標準偏差」に入る確率

標準正規分布（平均0・標準偏差1）で、各範囲に入る確率を求めます。

```r
# 平均±1σ に入る確率
pnorm(1) - pnorm(-1)      # 約68%

# 平均±2σ に入る確率
pnorm(2) - pnorm(-2)      # 約95%
```

出力:

```text
[1] 0.6826895
[1] 0.9544997
```

**「±1σに約68%、±2σに約95%」**——これは正規分布の有名な性質（68-95-99.7則）です。測定値のばらつきを解釈する基準になります。

---

## 3. 任意の平均・標準偏差の分布

`mean` と `sd` を指定できます。例：真の値100・標準偏差2の測定で、98〜102に入る確率。

```r
# 平均100・標準偏差2 の分布で、98以上102以下になる確率
pnorm(102, mean = 100, sd = 2) - pnorm(98, mean = 100, sd = 2)
```

出力:

```text
[1] 0.6826895
```

98〜102（＝平均±1σ）に約68%が入る、と分かります。

!!! success "検定の土台"
    正規分布と確率の考え方は、次回以降の**仮説検定**（t検定・分散分析など）の土台です。「この結果は偶然か、意味のある差か」を判断する基準になります。

---

## 演習問題

**問1.** `pnorm(1.645)` を計算してください（上側5%点に対応。90%信頼区間で使う値です）。

**問2.** 標準正規分布で「平均±3σ」に入る確率を、`pnorm(3) - pnorm(-3)` で計算してください（99.7%になるはずです）。

**問3.** 平均50・標準偏差5の分布で、45以下になる確率を `pnorm(45, mean = 50, sd = 5)` で計算してください。

---

## 解答

??? success "問1 の解答"
    ```r
    pnorm(1.645)     # [1] 0.9500151
    ```
    約0.95。1.645 は片側5%（両側10%）の基準値です。

??? success "問2 の解答"
    ```r
    pnorm(3) - pnorm(-3)     # [1] 0.9973002
    ```
    約99.7%。これで「68-95-99.7則」がそろいました。

??? success "問3 の解答"
    ```r
    pnorm(45, mean = 50, sd = 5)     # [1] 0.1586553
    ```
    45（＝平均−1σ）以下になる確率は約16%です。

---

## この回のまとめ

- 正規分布は釣鐘型。多くの測定誤差が従う。
- `dnorm`（密度）・`pnorm`（累積確率）・`qnorm`（分位点）・`rnorm`（乱数）。
- 68-95-99.7則：±1σに68%、±2σに95%、±3σに99.7%。
- 1.96（両側5%）、1.645（片側5%）は検定でよく使う値。
