    第8回　まとめ演習：ミニ分子量電卓アプリをつくる¶

    この回のゴール

    • これまでの 変数・型・リスト・辞書・if・for・関数 を全部使う
    • input() でユーザーと対話するプログラムを書く
    • 小さな「アプリ」を完成させ、動かす喜びを味わう
    • 所要時間の目安: 60分（第1部の総仕上げ）

    molar_calculator.py という名前で作りましょう。今回は少し長めですが、全部これまでの復習です。

    1. input()：ユーザーに入力してもらう¶

    input() は、キーボードからの入力を受け取る命令です。受け取った値は必ず文字列（str）になるので、数として使うときは float() や int() で変換します。

    name = input("あなたの名前は？ > ")
print(f"こんにちは、{name} さん！")

mass_text = input("質量[g]を入力 > ")   # 文字列で入ってくる
mass = float(mass_text)                # 数（小数）に変換
print(f"入力された質量は {mass} g です")

    実行例（> の後があなたの入力）:

    あなたの名前は？ > 太郎
こんにちは、太郎 さん！
質量[g]を入力 > 18.0
入力された質量は 18.0 g です

    変換を忘れると計算がおかしくなる

    input() の結果は文字列です。"3" + "4" は "34"（文字の連結）になってしまいます。数として足したいなら float(...) で変換してから。

    2. 設計を考える¶

    いきなり全部書かず、「何をするアプリか」を先に決めます。

    作るもの：ミニ分子量電卓

    1. 登録済みの分子から1つ選ぶ（水・二酸化炭素・エタノール・グルコース…）
    2. そのモル質量を表示する
    3. 質量[g]を入力すると、物質量[mol]と分子数も計算する
    4. 「続ける／やめる」を選べる（while でくり返す）

    必要な部品はすべて第1〜7回で学びました。組み立てるだけです。

    3. 完成版コード（そのままコピペで動きます）¶

    molar_calculator.py
    # ===== ミニ分子量電卓アプリ =====

# 原子量表
ATOMIC_MASS = {
    "H": 1.008, "C": 12.011, "N": 14.007, "O": 15.999,
    "Na": 22.990, "S": 32.06, "Cl": 35.453,
}
AVOGADRO = 6.022e23

# 登録済みの分子（名前: 組成の辞書）
MOLECULES = {
    "水":        {"H": 2, "O": 1},
    "二酸化炭素": {"C": 1, "O": 2},
    "エタノール": {"C": 2, "H": 6, "O": 1},
    "グルコース": {"C": 6, "H": 12, "O": 6},
}


def molar_mass(composition):
    """組成の辞書からモル質量[g/mol]を返す"""
    total = 0.0
    for symbol, count in composition.items():
        total += ATOMIC_MASS[symbol] * count
    return total


def show_menu():
    """登録分子を番号つきで表示する"""
    print("\n--- 分子を選んでください ---")
    for i, name in enumerate(MOLECULES, start=1):
        print(f"  {i}. {name}")
    print("  0. おわる")


# ===== メインの流れ =====
names = list(MOLECULES)      # 分子名を番号で選べるようリスト化

print("ミニ分子量電卓へようこそ！")

while True:                                  # 「やめる」まで繰り返す
    show_menu()
    choice = input("番号を入力 > ")

    if choice == "0":
        print("おつかれさまでした！")
        break                                # ループを抜けて終了

    # 入力が 1〜分子数 の範囲の数字かチェック
    if not choice.isdigit() or int(choice) < 1 or int(choice) > len(names):
        print("！ 正しい番号を入力してください")
        continue                             # やり直し

    # 選ばれた分子
    name = names[int(choice) - 1]            # 番号は1始まり、リストは0始まり
    comp = MOLECULES[name]
    mm = molar_mass(comp)
    print(f"\n【{name}】のモル質量は {mm:.3f} g/mol です")

    # 質量を入れてもらって、物質量と分子数を計算
    mass_text = input(f"{name} は何 g ありますか？（不要なら Enter）> ")
    if mass_text.strip() != "":
        mass = float(mass_text)
        n = mass / mm
        molecules = n * AVOGADRO
        print(f"  → {mass} g は {n:.3f} mol")
        print(f"  → 分子はおよそ {molecules:.3e} 個")

    実行してみよう¶

    ターミナルで python molar_calculator.py を実行します。対話の例:

--- 分子を選んでください ---
  1. 水
  2. 二酸化炭素
  3. エタノール
  4. グルコース
  0. おわる
番号を入力 > 4

【グルコース】のモル質量は 180.156 g/mol です
グルコース は何 g ありますか？（不要なら Enter）> 90

  → 90.0 g は 0.500 mol
  → 分子はおよそ 3.008e+23 個

--- 分子を選んでください ---
  1. 水
  ...
番号を入力 > 0
おつかれさまでした！

    おめでとうございます！

    これで、あなたは動くアプリを1つ完成させました。使った道具を数えてみましょう——変数・型・f-string・辞書・リスト・関数・for・while・if・input・型変換。第1部で学んだことが全部つながっています。ここまで来れば、もう立派なプログラマーです。

    この長いコードの読み解き方¶

    一度に全部理解できなくて大丈夫です。部品ごとに見ると簡単です。

    1. ATOMIC_MASS / MOLECULES … データ（辞書）
    2. molar_mass() / show_menu() … 部品（関数）
    3. while True: の中 … メインの流れ（選ぶ → 計算 → 表示 → くり返す）

    AIと一緒に読む

    分からない行は、その行をコピーしてAI（Claude / ChatGPT）に「この行は何をしている？」と聞いてみましょう。答えを写すのではなく、説明を読んで自分で納得するのがコツです。

    演習問題¶

    問1. MOLECULES に、あなたの好きな分子を1つ追加してください。例：アンモニア \(NH_3\)（{"N": 1, "H": 3}）や メタン \(CH_4\)（{"C": 1, "H": 4}）。追加後にアプリを動かし、メニューに出ることを確認しましょう。

    問2. molar_mass() に加えて、質量とモル質量から物質量を返す関数 moles(mass, mm) を新しく定義し、メインの計算部分をその関数を使う形に書き換えてください（動きは同じでも、部品に分けると読みやすくなります）。

    問3.（発展）アプリに「選んだ分子の元素の種類の数を表示する」機能を足してください。ヒント：組成の辞書 comp に対して len(comp) が元素の種類数になります。

    解答¶

    問1 の解答

    MOLECULES の辞書に行を足すだけです。 

    MOLECULES = {
    "水":        {"H": 2, "O": 1},
    "二酸化炭素": {"C": 1, "O": 2},
    "エタノール": {"C": 2, "H": 6, "O": 1},
    "グルコース": {"C": 6, "H": 12, "O": 6},
    "アンモニア": {"N": 1, "H": 3},   # 追加
    "メタン":     {"C": 1, "H": 4},   # 追加
}
    追加した分子がメニュー（5番・6番）に表示されれば成功です。

    問2 の解答

    関数を1つ足し、メインの計算部分を置き換えます。 

    def moles(mass, mm):
    """質量[g]とモル質量[g/mol]から物質量[mol]を返す"""
    return mass / mm

# メインの計算部分（該当箇所を置き換え）
if mass_text.strip() != "":
    mass = float(mass_text)
    n = moles(mass, mm)              # 関数を使う形に
    molecules = n * AVOGADRO
    print(f"  → {mass} g は {n:.3f} mol")
    print(f"  → 分子はおよそ {molecules:.3e} 個")

    問3 の解答

    モル質量を表示した直後に1行足します。 

    mm = molar_mass(comp)
print(f"\n【{name}】のモル質量は {mm:.3f} g/mol です")
print(f"  （{len(comp)} 種類の元素からできています）")   # 追加
    例：グルコース {"C":6, "H":12, "O":6} なら 3 種類の元素 と表示されます。
