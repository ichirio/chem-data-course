    第103回　AIを研究の相棒にする（プロンプトと検証）¶

    この回のゴール

    • AI（Claude / ChatGPT）を研究・学習に活かす方法を知る
    • 効果的な指示（プロンプト）の書き方を学ぶ
    • AI の出力を検証する姿勢を身につける
    • このコースで学んだ「AIが間違えやすい点」を、出力を確かめるチェックリストとして使えるようになる
    • 所要時間の目安: 60分

    このコースを通じて「AIに書かせて、自分で検証する」と繰り返してきました。最終章で、AI との正しい付き合い方を1つにまとめます。AI時代に最も大切な技能です。

    1. AI ができること・苦手なこと¶

    得意 苦手・注意
    コードの下書き・説明 事実の正確さ（もっともらしい嘘＝ハルシネーション）
    エラーの原因診断 最新情報（例：削除された関数 mean_squared_error(squared=False) や pandas の df.append を今も書く）
    アイデア出し・要約 単位・定義の取り違え（例：無水物と水和物、平均分子量と精密質量）
    定型作業の効率化 あなたのデータの正しい解釈（文脈依存）

    AI は「自信満々に間違える」

    AI は、間違った答えももっともらしく返します。特に、存在しない関数名・不正確な数値・でっち上げの文献に注意。AI の答えは「下書き」であって「正解」ではありません。

    2. 効果的なプロンプト（指示）¶

    AI に良い助けをもらうコツは、具体的に・文脈を添えて聞くことです（第18回のデバッグでも触れました）。

    コードを頼むときの6つの要素

    1. 目的：何を知りたいか（例：3種類の触媒で収率に差があるか）
    2. 入力データの形：ファイル名・列名・行数・1行が何を表すか（例：yield.csv、列 catalyst, yield_pct、1行＝1回の反応）
    3. 単位：各列の単位（%、mg/L、℃、g/mol…）。単位を書かないと、AI は勝手に仮定します
    4. 使うライブラリ：pandas・RDKit・scikit-learn など、授業で学んだもの（バージョンも）
    5. 期待する出力：表・図・数値の形（例：触媒ごとの平均と標準偏差の表、箱ひげ図を PNG で）
    6. 制約と確認用の出力：「生データを上書きしない」「seed は 42」「途中で行数と欠損数を print する」など

    悪い例：「エラーが出ました。直して」 良い例：「pandasで df['yield'].fillna() を使ったら TypeError が出ました。コードとエラー全文はこれです（貼付）。df.dtypes の結果も貼ります。原因と直し方を教えてください」

    化学データのコードを頼むプロンプト（テンプレート）

    目的：◯◯を調べたい。
データ：data/◯◯.csv（◯行）。列は A（単位）、B（単位）、C（カテゴリ：x/y/z）。欠損は空欄。
使うもの：Python 3.11、pandas、RDKit、scikit-learn 1.8。
出力：◯◯の表と◯◯の図（results/ に保存）。
制約：data/ のファイルは上書きしない。乱数は seed 42。
確認用：読み込み直後に shape・dtypes・欠損数を print。途中で行数が変わったら理由を print。
最後に、コードが置いている前提（単位・欠損の扱いなど）を箇条書きで説明してください。

    3. いちばん大事：検証する¶

    AI の出力は、必ず自分で確かめてから使います。

    検証の3ステップ

    1. 実行する：コードなら動かして、結果を見る。
    2. 確かめる：数値なら検算、事実なら一次情報を確認。
    3. 理解する：なぜそうなるかを、自分の言葉で説明できるようにする。

    このコースで数値を必ず Python/R で検証してきたのは、この姿勢を身につけるためです。「AIが言ったから正しい」ではなく「自分で確かめたから正しい」。これが研究者の態度です。

    AIが間違えやすく、人が見抜くべきポイント¶

    このコースの各回で学んだことは、そのまま AI の出力を確かめる「チェックリスト」になります。

    見るところ AIがやりがちな誤り 確かめ方（学んだ回）
    単位 mg/L と g/L、℃ と K、mL と L の取り違え 結果の桁が化学的にありうるか（第27・28回）
    物質の定義 水和物を無水物で計算、平均分子量の代わりに精密質量 既知の値（例：CuSO₄·5H₂O は 249.7 g/mol）と比べる（第59回）
    SMILES 別の化合物の SMILES、MolFromSmiles が None で行が消える 分子量の検算、入力数と出力の行数を比べる（第56・57回）
    データ型・欠損 数値が文字列のまま、欠損を 0 で埋める df.dtypes・df.isna().sum() を print（第35・41回）
    浮動小数点 == で小数を比べる np.isclose を使っているか（第29回）
    乱数 seed が効いていない 2回実行して一致するか（第26・102回）
    機械学習 学習に使ったデータで評価、前処理のデータ漏洩 fit の引数、パイプラインの有無（第95・96回）
    適用範囲 学習データと似ていない分子にも予測値を出す 学習データの範囲と比べる（第100回）
    統計 3群を t 検定の繰り返しで比較 分散分析＋事後検定か（第81回）
    情報の新しさ 削除された関数、存在しない関数・文献 実行する、公式ドキュメント・DOI で確かめる

    実演：指示 → 確認 → 修正 を一周する¶

    「SMILES からモル質量を返す関数」を AI に頼んだとします。返ってきたのが次の関数でした。

    from rdkit import Chem
from rdkit.Chem import Descriptors

def molar_mass(smiles):
    return Descriptors.MolWt(Chem.MolFromSmiles(smiles))

    確認1：答えの分かっている分子で試す。水・エタノール・ベンゼンのモル質量は分かっています。

    checks = {"O": 18.015, "CCO": 46.069, "c1ccccc1": 78.114}   # 答えの分かっている分子
for smi, expected in checks.items():
    got = molar_mass(smi)
    ok = "OK" if abs(got - expected) < 0.01 else "NG"
    print(f"{smi:10s} 期待 {expected:7.3f}  結果 {got:7.3f}  {ok}")

    出力:

    O          期待  18.015  結果  18.015  OK
CCO        期待  46.069  結果  46.069  OK
c1ccccc1   期待  78.114  結果  78.114  OK

    確認2：わざと悪い入力を入れる。環が閉じていない SMILES "C1CC" を入れると、RDKit の SMILES Parse Error の後に ArgumentError（_CalcMolWt(NoneType) …）という分かりにくいエラーで止まります。MolFromSmiles が None を返したことを、関数がチェックしていないからです。

    修正：AI に「None のときは、どの SMILES が読めなかったか分かる ValueError を出すように直して」と頼み、同じ確認をやり直します。

    def molar_mass(smiles):
    """SMILES から平均分子量 [g/mol] を返す。読めない SMILES はエラーにする。"""
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        raise ValueError(f"SMILES を解釈できません: {smiles}")
    return Descriptors.MolWt(mol)

try:
    molar_mass("C1CC")          # わざと壊れた SMILES を入れてみる
except ValueError as e:
    print("エラー:", e)

    出力（RDKit のエラーメッセージ行の後に）:

    エラー: SMILES を解釈できません: C1CC

    このように、正しい入力で答えが合うか・おかしな入力で正しく失敗するかの2つを確かめる小さなコードは、AI に書かせてもかまいません。ただし「期待する値」（18.015 など）は、自分で教科書やデータベースから用意します。答えまで AI に作らせると、確認になりません。

    AIに確認を手伝わせる頼み方

    • 「このコードが置いている前提（単位・欠損の扱い・列の意味）を箇条書きにして」→ 自分の意図と違う前提がないか読む。
    • 「途中の shape・dtypes・行数を print する行を入れて」→ 途中経過を自分の目で見る。
    • 「答えの分かっている入力で試すテストを書いて。期待値は私が書きます」
    • 別の AI、または新しい会話で「このコードの誤りを探して」と頼む（同じ会話では、自分の書いたコードを擁護しがち）。

    4. 研究での上手な使い方¶

    • 学習の相棒：分からない概念・コードの意味を聞く（答えを写さず、理解する）。
    • コードの下書き：たたき台を作らせ、自分で検証・修正する。
    • デバッグ：エラー全文を見せて原因を相談する（第18回）。
    • 要約・整理：大量の情報の下ごしらえ（ただし事実は原典で確認）。

    やってはいけないこと

    • AI の答えを検証せずにレポート・論文に載せる。
    • AI に生成させた文章を、自分が書いたことにする（研究倫理・剽窃の問題）。多くの学術誌・大学は、AI を著者にできないこと、使った場合は方法や謝辞に記載することを定めています。提出先の規定を必ず確認しましょう。
    • 機密データ・未公開データを不用意に外部AIに送る（データ管理、第104回）。未公開の化合物構造・共同研究先のデータ・個人情報は送らない。コードを頼むときは、列名と数行のダミーデータを見せれば十分です。所属機関の AI 利用ルールも確認します。
    • AI が挙げた文献をそのまま引用する。存在しない論文や、内容の違う論文が挙がることがあります。DOI を開いて、原典を自分で読んでから引用します。

    AI は強力な道具ですが、責任と判断は常に人間にあります。

    AIに任せるときの指示と確認¶

    AIへの頼み方（例）

    「溶液調製の計算を Python で書いてください。試薬は硫酸銅(II)五水和物 CuSO₄·5H₂O（水和水を含む）、目標は 0.100 mol/L を 250 mL です。 モル質量は RDKit の Descriptors.MolWt（平均分子量）で、水和水を含む SMILES から計算してください。 組成式（CalcMolFormula）・モル質量 [g/mol]・必要な質量 [g] を表示し、体積は L に換算してから計算してください。 コードが置いている前提（試薬の形・単位）も最後に箇条書きで説明してください。」

    AIの出力で確かめること

    • 物質の定義：SMILES が無水物（CuSO₄）になっていないか。CalcMolFormula の結果に H10…O9 のように水和水が入っているか。
    • 平均分子量と精密質量：秤量に使うのは MolWt（平均分子量）。ExactMolWt は質量分析で使うモノアイソトピック質量で、値が少し違う。
    • 単位：mL を L に換算しているか。「mol/L × mL」を 1000 で割り忘れる・二重に割る誤りがないか、最後の質量の桁（数 g）が妥当か。
    • 既知の値と照合：CuSO₄·5H₂O のモル質量は 249.7 g/mol（試薬瓶のラベルや化学便覧で確認）。
    • 前提の説明：AI が書いた「前提」の箇条書きが、自分の実験（使う試薬・メスフラスコの容量）と一致しているか。

    演習問題¶

    問1. 「悪いプロンプト」と「良いプロンプト」の違いを、自分の言葉で説明してください。良いプロンプトに必要な要素を3つ挙げましょう。

    問2. AI にコードを書いてもらったとき、それを使う前に行うべき「検証の3ステップ」を挙げてください。

    問3. 実際に、これまでの学習で分からなかったことを1つ、AI（Claude / ChatGPT）に「目的・文脈・具体物」を添えて質問してみてください。得られた答えを、自分で実行・検証しましょう。

    問4. 次は、「硫酸銅(II)五水和物で 0.100 mol/L の水溶液を 250 mL つくるのに必要な質量」を求めるために AI が書いたコードと出力です。問題点を2つ指摘し、直してください。

    from rdkit import Chem
from rdkit.Chem import Descriptors

# 硫酸銅(II)五水和物で 0.100 mol/L の水溶液を 250 mL つくるのに必要な質量
smiles = "[Cu+2].[O-]S(=O)(=O)[O-]"
M = Descriptors.ExactMolWt(Chem.MolFromSmiles(smiles))     # モル質量 [g/mol]
c = 0.100      # [mol/L]
V = 250        # [mL]
mass = c * V * M / 1000
print(f"モル質量: {M:.2f} g/mol")
print(f"必要な質量: {mass:.3f} g")

    出力:

    モル質量: 158.88 g/mol
必要な質量: 3.972 g

    解答¶

    問1 の解答

    悪いプロンプトは曖昧（「直して」だけ）。良いプロンプトは具体的で文脈がある。必要な要素は (1) 目的、(2) 文脈（道具・データ）、(3) 具体物（コード・エラー全文）。加えて (4) 制約（初心者向けに、など）があるとなお良い。

    問2 の解答

    (1) 実行する（動かして結果を見る）、(2) 確かめる（数値は検算、事実は原典確認）、(3) 理解する（なぜそうなるか自分の言葉で説明できるように）。この3つを経て初めて、AI の出力を「使える」ものにします。

    問3 の解答・確認ポイント

    例：「Pythonのpandasで、CSVを読み込んで特定の列の平均を出したいです。初心者向けにコードを教えてください」のように、目的・道具・レベルを添えて質問します。得られたコードは必ず自分で実行し、期待どおり動くか・意味が分かるかを確認しましょう。分からない部分は、さらに「この行は何をしている？」と聞き返すのが効果的です。

    問4 の解答

    誤り1（化学的な誤り：水和水）：SMILES が無水の CuSO₄ です。使う試薬は五水和物なので、水和水 5 分子を含めたモル質量（249.7 g/mol）で計算しなければなりません。このままだと必要量の約 64 % しか量らず、濃度が 0.064 mol/L 程度の溶液になります。

    誤り2（平均分子量と精密質量）：ExactMolWt は最も多い同位体だけで計算したモノアイソトピック質量（質量分析用）です。秤量には天然同位体比の平均である MolWt を使います（無水 CuSO₄ で 159.61 と 158.88 の差）。

    確かめ方：CalcMolFormula で組成式を表示する。試薬瓶のラベルや化学便覧のモル質量（CuSO₄·5H₂O = 249.69 g/mol）と比べる。

    from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

# 硫酸銅(II)五水和物 CuSO4·5H2O：水和水も SMILES に含める
smiles = "[Cu+2].[O-]S(=O)(=O)[O-].O.O.O.O.O"
mol = Chem.MolFromSmiles(smiles)
print("組成式:", rdMolDescriptors.CalcMolFormula(mol))
M = Descriptors.MolWt(mol)          # 平均分子量（天然同位体比）＝秤量に使うモル質量
c = 0.100      # [mol/L]
V = 0.250      # [L]
mass = c * V * M
print(f"モル質量: {M:.2f} g/mol")
print(f"必要な質量: {mass:.3f} g")

    出力: 

    組成式: H10CuO9S
モル質量: 249.68 g/mol
必要な質量: 6.242 g
    体積も最初から L で書くと、「/1000」の付け忘れ・二重付けを防げます。
